WBS는 프로젝트의 일을 큰 덩어리에서 작은 작업으로 잘게 나눈 계획표입니다. D-Flow에서는 왼쪽 메뉴의 **작업 계획** 화면이 이 계획표입니다. 작업마다 담당 팀, 계획 일정, 진척(실적)이 적혀 있고, 작은 작업의 진척을 모으면 그 윗줄의 진척이 자동으로 계산됩니다.

같은 작업을 세 가지 모양으로 볼 수 있습니다.

- **표**: 작업을 한 줄씩 보고 숫자(일정·가중치·실적)를 확인합니다. 오른쪽에는 일정 막대도 함께 그려집니다. 값을 고치는 일은 이 보기에서 합니다.
- **간트**: 열을 줄이고 일정 막대(간트 차트)를 넓게 보여 줍니다. 작업이 언제 겹치는지 한눈에 볼 때 씁니다.
- **보드**: 작업을 카드로 만들어 진행 상태별 칸에 늘어놓습니다(칸반). 프로젝트에서 칸반 기능이 켜져 있을 때만 보입니다.

이 장에서 '계층'은 계획표의 층(맨 위 층, 그 아래 층…)을 뜻하고, '업무 흐름 단계'는 작업이 거치는 진행 단계(할당됨, 작업 중 등)를 뜻합니다. 표의 **단계** 열은 업무 흐름 단계이고, 보드의 '…별' 탭 이름은 프로젝트가 정한 계층 이름입니다.

이 장에서 할 수 있는 일은 다음과 같습니다.

- 작업을 보고, 접고 펼치고, 원하는 작업만 남겨 보고, 이름으로 찾기
- 내 팀 작업의 실적%(진척) 입력하고 되돌리기
- 작업 상세 패널에서 일정, 선행 작업, 산출물, 변경 이력 확인하기
- 업무 흐름 단계와 승인 이해하기
- 보드에서 카드로 진척 옮기기
- 키보드로 표를 다루고, 여러 칸을 복사해 붙여넣기

## 작업 계획 화면 열기

1. 일할 프로젝트에 들어갑니다. 프로젝트를 고르는 방법은 [프로젝트와 대시보드](/help/projects-dashboard) 장을 보세요.
2. 왼쪽 메뉴에서 **계획** 묶음 아래의 **작업 계획**을 누릅니다.

화면 맨 위에 제목 **작업 계획**이 보입니다. 그 아래에 보기를 바꾸는 스위치(**표**, **간트**, **보드**), 도구 줄, 작업 표가 차례로 나옵니다.

처음에는 프로젝트 관리자가 정해 둔 기본 보기로 열립니다. 따로 정하지 않았다면 **표**로 열립니다.

### 다른 화면에서 작업을 눌러 들어왔을 때

대시보드, 보드의 카드, 제목 검색 결과에서 작업을 누르면 **표**로 열립니다. 접혀 있던 윗줄이 자동으로 펼쳐지고, 그 작업 줄이 화면 가운데로 옮겨 가서 잠깐 강조됩니다. 그 작업이 지워졌거나 목록이 바뀌어 찾지 못하면 **이동하려는 작업을 찾을 수 없습니다 (삭제되었거나 목록이 바뀌었습니다)** 라는 안내가 나옵니다.

### 도구 줄 단추 알아보기

도구 줄의 단추는 화면 폭이 1600픽셀보다 좁으면 글자 없이 그림만 보입니다. 마우스를 올리면 이름이 나옵니다. 흔한 노트북 화면에서는 대부분 그림만 보이므로 아래 모양으로 찾으세요.

| 단추 모양 | 이름 | 하는 일 |
| --- | --- | --- |
| # 모양 | **개요 번호 열 표시/숨김** | **번호** 열을 켜고 끕니다. |
| 돋보기에 − 또는 + 가 있는 두 단추와 가운데 막대 | **간트 축소**, **간트 확대**, **간트 배율** | 간트 막대의 가로 배율을 바꿉니다. |
| 눈 모양 | **담당~계획% 숨기기** / **담당~계획% 펼치기** (글자가 보이면 **열 숨김** / **열 펼침**) | **담당팀**부터 **계획%**까지 열을 숨기거나 펼칩니다. 간트 보기에서는 이 단추가 없습니다. |
| 돋보기 모양(− + 표시 없음) | **진척 돋보기** (글자가 보이면 **돋보기**) | 줄의 진척을 아래 상자에 크게 보여 줍니다. |
| 줄 세 개와 체크 표시가 있는 목록 모양 | **완료 숨김** | 완료된 작업을 숨깁니다. 숨긴 수가 옆에 나옵니다. |
| **A−**, 숫자, **A+** | 글자 크기 | 표의 글자 크기를 바꿉니다. |
| 네 모서리에서 바깥으로 향한 화살표 모양 | **크게** / **작게** | 전체 화면으로 키우거나 닫습니다. |
| 반짝이 모양 | **AI** | 전체 화면에서만 나오고, AI를 쓸 수 있을 때 AI 도우미를 엽니다. |
| 깃발 모양 | **마일스톤** | 마일스톤 표시가 있을 때만 나옵니다. 세로 점선 표시를 켜고 끕니다. |
| 문서 모양 | **주간보고** | 주간 보고서 창을 엽니다. |
| 이름 두 글자가 든 동그라미들 | 접속자 | 지금 같은 화면을 보는 사람들입니다. 좁은 화면에서는 보이지 않습니다. |

### 같이 보고 있는 사람 표시

도구 줄 오른쪽 끝(좁은 화면에서는 보이지 않습니다)에 지금 이 작업 계획 화면을 보고 있는 사람들이 동그란 이름표로 나옵니다. 본인이 맨 앞이고, 이름 두 글자가 들어 있으며, 5명이 넘으면 **+2**처럼 줄여 보입니다. 마우스를 올리면 전체 이름이 보입니다. 다른 사람이 값을 고치면 **표**에는 곧바로 반영되어 내 화면도 따라 바뀝니다.

## 보기 바꾸기

1. 제목 아래 왼쪽의 스위치에서 보고 싶은 보기를 누릅니다.
2. 지금 보는 보기는 흰색 칸으로 표시됩니다.

**보드**가 스위치에 없다면 프로젝트나 워크스페이스에서 칸반 기능이 꺼져 있는 것입니다. 쓰고 싶으면 프로젝트 관리자에게 요청하세요.

보드 주소로 들어왔는데 보드를 쓸 수 없으면 **표**로 열리고 이유가 한 줄로 나옵니다.

- **이 프로젝트에서는 보드를 사용하지 않습니다**: 프로젝트에서 칸반을 꺼 둔 경우입니다. 관리자에게는 설정으로 가는 링크도 함께 보입니다.
- **워크스페이스에서 보드를 허용하지 않습니다**: 워크스페이스 설정에서 막혀 있는 경우입니다. **워크스페이스 관리자에게 문의하세요.** 라고 안내합니다.
- **보드 사용 여부를 확인하지 못했습니다**: 일시적으로 확인에 실패한 경우입니다. 잠시 뒤 다시 열어 보세요.

### 표와 간트의 차이

**표**는 모든 열을 보여 주고, **간트**는 **번호**, **작업명**, **담당팀**, **진척**, **단계** 열만 남겨 일정 막대 자리를 넓힙니다. 두 보기 모두 같은 작업 줄과 같은 막대를 보여 줍니다.

**간트**에는 가중치·실적% 같은 숫자 열이 없으므로 값을 고칠 수 없습니다. 값을 고치려면 **표**를 누르세요. **간트** 보기 아래 안내에도 **편집은 ‘표’ 보기로 전환**이라고 적혀 있습니다. 보기 스위치에서 **표**를 누르면 됩니다.

## 표의 열 읽는 법

**표**에서 왼쪽부터 보이는 열은 다음과 같습니다. 프로젝트에 따라 일부 열은 보이지 않습니다.

| 열 | 보이는 내용 |
| --- | --- |
| 맨 왼쪽 줄 번호 | 줄 번호입니다. 관리자에게는 줄을 고르는 체크 칸이 보입니다. 칸 왼쪽의 색 띠는 맨 위 계층 항목별로 색이 다릅니다. |
| **번호** | 1, 1.1, 1.2.1 같은 개요 번호입니다. 처음에는 꺼져 있습니다. |
| **작업명** | 작업 이름입니다. 단계가 깊을수록 오른쪽으로 들어가 보입니다. 이름을 누르면 상세 패널이 열립니다. |
| **담당팀** | 맡은 팀의 이름입니다. 앞의 ● 표시는 주관 팀, △ 표시는 지원 팀입니다. |
| **담당자** | 개인 담당자 이름입니다. 프로젝트에 담당자가 지정된 작업이 하나도 없으면 이 열 자체가 보이지 않습니다. |
| **진척** | 작업 상태입니다. **시작전**, **진행중**, **지연**, **완료** 중 하나입니다. |
| **단계** | 업무 흐름 단계입니다. 에이전트에게 맡긴 작업이 하나라도 있는 프로젝트에서만 보입니다. |
| **산출물** | 이 작업의 결과물 이름입니다. |
| **계획시작**, **계획종료** | 계획한 시작일과 종료일입니다. 연도 네 자리로 표시됩니다. |
| **가중치** | 같은 윗줄 아래 작업들이 윗줄 진척에 반영되는 비율입니다. |
| **계획%** | 오늘까지 일정대로라면 얼마나 진행되어 있어야 하는지입니다. |
| **실적%** | 실제 진척입니다. 칸 배경에 진척만큼 색 막대가 깔립니다. |
| **계획대비** | 실적을 계획으로 나눈 값입니다. 계획이 0이면 **—** 로 나옵니다. 값이 클수록 일정보다 앞서 있는 것이고, 색으로도 구분됩니다. |
| 추가 정보 열 | 프로젝트 관리자가 목록에 보이게 설정한 항목입니다. 이름은 프로젝트마다 다릅니다. |

### 날짜 칸의 색과 모양

- 기울어진 연한 글씨: 하위 작업에서 계산된 날짜입니다. 칸에 마우스를 올리면 **하위 작업에서 계산됨**이라고 나옵니다.
- 주황색 굵은 글씨: 프로젝트 기간을 벗어난 날짜입니다. 마우스를 올리면 **프로젝트 기간을 벗어난 일정**이라고 나옵니다. 표 위에는 **프로젝트 기간 밖 작업 3건 — 프로젝트 기간(2026-01-05 ~ 2026-06-30)을 벗어난 일정이 있습니다. 해당 행의 날짜가 강조됩니다.** 같은 안내도 함께 나옵니다. 저장을 막지는 않고 알려만 줍니다.

### 가중치 칸 읽기

맨 위 계층 항목에 가중치를 적어 둔 경우, 가중치 열 이름 아래에 그 합계가 괄호로 나옵니다. 합이 100%가 아니면 빨간색으로 바뀌므로 비율을 나눈 방식을 다시 확인하라는 신호입니다.

가중치를 비워 둔 칸에는 **균등**이라고 나옵니다. 같은 윗줄 아래에서 일부만 가중치를 정하면, 비워 둔 작업은 남은 몫(100%에서 정한 값의 합을 뺀 값)을 똑같이 나눠 받습니다. 이런 칸이 있으면 열 이름 아래에 **미지정 3개** 같은 글자가 나옵니다. 정한 값의 합이 이미 100% 이상이면 **남은 몫 없음**이 함께 나오고, 비워 둔 작업 칸은 **균등 (0%)** 로 바뀝니다. 그 작업은 윗줄 진척에 반영되지 않으니 프로젝트 관리자에게 비율을 다시 나눠 달라고 요청하세요.

## 상태와 진척 계산 이해하기

**진척** 열의 상태는 사람이 고르는 값이 아니라 계산된 값입니다.

- **완료**: 실적이 100%입니다.
- **시작전**: 시작일이 아직 오지 않았고 실적이 0%이거나, 계획도 0%이고 실적도 0%입니다.
- **지연**: 실적(반올림한 값)이 계획보다 낮습니다.
- **진행중**: 위에 해당하지 않을 때입니다.

계획%는 근무일을 기준으로 계산합니다. 오늘이 시작일 전이면 0%, 종료일 뒤이면 100%이고, 그 사이에는 시작일부터 오늘까지의 근무일을 전체 근무일로 나눈 값입니다. 주말과 휴무일은 프로젝트 달력에 따라 빠집니다.

하위 작업이 있는 윗줄의 실적%는 직접 입력하지 않습니다. 하위 작업의 실적%를 가중치 비율로 합쳐 자동으로 계산합니다. 예를 들어 하위 작업 둘의 가중치가 60%와 40%이고 실적이 각각 50%와 100%이면, 윗줄의 실적은 (0.6 × 50) + (0.4 × 100) = 70%입니다.

> **팁** 윗줄의 **실적%** 칸에 마우스를 올리면 **하위에서 자동 집계**라고 나옵니다. 값을 바꾸고 싶으면 그 아래 가장 아래 작업의 실적을 고치세요.

## 작업 줄 접고 펼치기

1. 하위 작업이 있는 줄의 **작업명** 칸 왼쪽에서 화살표를 누릅니다. 아래로 향하면 펼쳐진 것이고 오른쪽으로 향하면 접힌 것입니다.
2. 접힌 줄 오른쪽에는 숨은 하위 작업 수가 작은 숫자로 나옵니다.

표 맨 위 **작업명** 칸의 오른쪽 가장자리를 끌면 열 폭을 바꿀 수 있고(마우스를 올리면 **작업명 열 폭 조절 — 드래그로 조정**), 이 브라우저에 저장됩니다.

표 맨 위 **작업명** 칸 아래에는 **1**, **2**, **3** 같은 숫자 단추가 있습니다. 숫자를 누르면 그 계층까지만 펼칩니다. **1**은 맨 위 계층만 남기는 전체 접기이고, 가장 큰 숫자는 전체 펼치기입니다. 단추에 마우스를 올리면 **전체 접기**, **전체 펼치기**, **이 레벨까지 펼치기 — 2** 같은 설명이 나옵니다.

내가 접고 펼친 상태는 프로젝트별로 내 계정에 저장되어 다음에 열어도 그대로입니다. 저장된 상태가 없는 처음에는 한 작업을 팀별로 나눠 둔 줄이 접혀 있습니다. 도구 줄의 # 모양 단추(마우스를 올리면 **개요 번호 열 표시/숨김**)로 번호 열을 켜고 끄며, 켜고 끈 상태도 계정에 저장됩니다.

## 보고 싶은 작업만 보기

**표**와 **간트**에는 글자를 쳐서 좁히는 검색칸이나 필터가 없습니다. 대신 아래 방법을 씁니다.

- 완료된 작업 숨기기: 도구 줄의 체크 목록 모양 **완료 숨김** 단추를 누릅니다. 마우스를 올리면 **완료된 작업 숨기기 — 전부 완료된 구간만 숨기고, 진행 중 구간의 완료 작업은 흐리게 유지**라고 나옵니다. 숨긴 작업 수가 단추 옆에 숫자로 나옵니다. 이 설정은 모든 프로젝트에 공통으로 계정에 저장됩니다.
- 열 줄여서 보기: 눈 모양 단추(마우스를 올리면 **담당~계획% 숨기기**, 넓은 화면에서는 **열 숨김** 글자)를 누르면 **담당팀**부터 **계획%**까지 숨깁니다. 다시 누르면 **담당~계획% 펼치기**로 바뀌며 열이 돌아옵니다. 이 상태는 저장되지 않고, 화면을 다시 열면 펼쳐진 상태로 돌아옵니다. 폭이 좁은 화면에서는 처음부터 숨긴 채 열립니다.
- 줄 접기: 앞의 [작업 줄 접고 펼치기](#작업-줄-접고-펼치기)를 보세요.
- 보드의 필터와 검색: [보드에서 필터와 검색 쓰기](#보드에서-필터와-검색-쓰기)를 보세요.

모든 작업이 완료되어 숨겨지면 **모든 작업이 완료되어 숨겨졌습니다**라는 안내와 **숨기기 해제** 단추가 나옵니다.

## 작업 이름으로 찾기

1. 화면 맨 위 줄의 **제목 검색...** 단추를 누릅니다. 키보드로는 Ctrl+K(맥에서는 ⌘+K)를 누릅니다. 좁은 화면에서는 돋보기 모양 단추가 같은 일을 합니다.
2. 검색창이 열리면 **범위:** 옆에서 현재 프로젝트 이름 단추가 선택되어 있는지 확인하고 찾을 말을 입력합니다. **워크스페이스 전체**를 고르면 프로젝트 이름을 찾습니다.
3. 결과 목록에서 **WBS 작업**이라고 표시된 줄을 위아래 방향키나 마우스로 고르고 Enter를 누릅니다.

고른 작업이 있는 **작업 계획** 화면이 열리고 그 줄로 이동합니다. 이 검색은 작업의 이름과 코드만 찾습니다. **제목 검색 전용**이라고 적혀 있듯 내용까지 찾지는 않습니다. 메뉴 이름을 치면 그 화면으로 바로 이동하는 결과도 함께 나옵니다. 결과가 없으면 **‘회의’ 제목과 일치하는 결과가 없습니다**처럼 찾은 말과 함께 안내가 나옵니다. Esc를 누르면 닫힙니다.

## 진척 돋보기 쓰기

줄이 많은 표에서 한 작업의 진척을 크게 보고 싶을 때 씁니다.

1. 도구 줄에서 돋보기 모양 단추(글자는 **돋보기**, 마우스를 올리면 **행의 진척 정보를 크게 확인**)를 누릅니다.
2. 화면 아래에 **진척 돋보기** 상자가 나오고 **행에 마우스를 올리거나 작업명에 키보드 포커스를 이동하세요**라고 안내합니다. 보고 싶은 줄에 마우스를 올리면 됩니다.
3. 줄 위에 마우스를 올리면 아래 상자에 그 작업의 상태, 담당 팀, 일정, 산출물, 계획%, 실적%, **계획 대비 차이**, **계획대비**와 진척 막대가 크게 나옵니다.
4. 한 작업에 계속 머무르고 싶으면 줄을 누르거나 상자의 **고정** 단추를 누릅니다. 고정되면 **고정됨 · 다른 행을 보려면 고정을 해제하세요**라고 나옵니다. **고정 해제**를 누르면 풀립니다.
5. Esc를 누르면 선택이 풀리고, 돋보기 단추를 다시 누르면 돋보기가 꺼집니다.

상자 오른쪽의 점 여섯 개 손잡이를 끌면 상자 위치를 옮길 수 있습니다. 돋보기를 끄면 위치가 처음으로 돌아옵니다.

## 간트 막대 읽는 법

일정 막대는 작업 줄마다 오른쪽 날짜 칸에 그려집니다.

- 막대 전체: 계획한 시작일부터 종료일까지입니다.
- 막대 안쪽의 색 채움: 실적%만큼입니다. 색은 상태와 같습니다(시작전, 진행중, 지연, 완료).
- 막대 옆이나 안의 숫자: 실적%입니다. 완료된 작업에는 숫자가 나오지 않습니다.
- 맨 위 계층의 막대는 더 가늘고 짙은 색 막대입니다.
- 흐리게 그려진 막대: 직접 입력한 일정이 아니라 하위 작업에서 계산한 일정입니다.
- 세로 선과 **오늘** 표시: 오늘 날짜입니다. 화면을 열면 오늘이 가운데쯤 오도록 가로 위치가 맞춰집니다.
- 바탕의 색 띠: 주말 같은 쉬는 요일(**비근무 요일**)과 **휴무** 날입니다. 맨 아래 범례에서 색을 확인할 수 있습니다. 범례는 작은 화면에서는 보이지 않습니다.
- 위쪽 날짜 머리: 월, 주, 일 세 줄입니다. 배율을 기본보다 줄이면 날짜 숫자 줄이 사라지고, 더 줄이면 주 단위 칸만 남습니다.

### 마일스톤 표시

가장 아래 작업 가운데 이름에 프로젝트 관리자가 정해 둔 키워드(예: 킥오프, 오픈)가 들어 있거나, 시작일과 종료일이 같은 하루짜리이면서 산출물이 적힌 작업은 종료일에 세로 점선과 이름표가 나옵니다. 상태는 색으로 구분되고 범례에 **예정**, **완료**, **지연**으로 나옵니다. 예정 이름표에는 D-5처럼 남은 날, 지연 이름표에는 D+3처럼 지난 날이 붙습니다. 이 표시가 하나라도 있으면 도구 줄에 깃발 모양 **마일스톤** 단추(마우스를 올리면 **마일스톤 기준선 표시/숨기기**)가 생깁니다.

### 선행 작업 선과 크리티컬 패스

- 막대 위에 마우스를 올리거나 줄을 선택해 상세 패널을 열면, 그 작업에 연결된 선행·후속 작업 사이에 화살표 선이 그려집니다. 실선은 **완료 후 시작(FS)**, 점선은 **동시 시작(SS)** 입니다.
- 이름 옆의 빨간 점과 빨간 테두리 막대는 **크리티컬 패스**입니다. 이 줄이 늦어지면 전체 일정이 밀리는 작업이라는 뜻입니다.
- 앞선 작업이 늦어져 일정이 밀리면 원래 막대 아래에 점선 막대로 **지연 반영 예상 일정**이 나옵니다.

범례에는 선행 작업이 하나라도 있는 프로젝트에서만 FS, SS, **크리티컬 패스**, **예상 일정** 표시가 나옵니다.

### 배율 바꾸기

1. 도구 줄의 돋보기에 + 또는 − 가 있는 단추(**간트 확대**, **간트 축소**)를 누르거나 가운데 슬라이더를 끕니다.
2. 슬라이더에 마우스를 올리면 **간트 배율**이라고 나옵니다.

배율은 계정에 저장되어 다음에도 그대로입니다. 오래 걸리는 프로젝트는 축소해 전체 흐름을 보고, 짧은 구간은 확대해 날짜 하나하나를 보세요.

> **주의** 간트 막대를 끌어서 일정을 옮기는 기능은 프로젝트 관리자에게만 있습니다. 일반 사용자가 막대를 끌어도 일정은 바뀌지 않습니다.

## 전체 화면과 글자 크기

### 전체 화면으로 크게 보기

1. 도구 줄의 네 모서리 바깥 화살표 모양 단추(넓은 화면에서는 **크게** 글자)를 누릅니다. 마우스를 올리면 **전체화면으로 크게 보기**라고 나옵니다.
2. 닫으려면 같은 자리의 **작게** 단추(**전체화면 닫기 (Esc)**)를 누르거나 Esc를 누릅니다.

상세 패널, 돋보기, 입력 중인 칸이 열려 있으면 Esc는 먼저 그것을 닫고, 한 번 더 누르면 전체 화면이 닫힙니다. AI 도우미를 쓸 수 있는 프로젝트에서는 전체 화면 도구 줄에 **AI** 단추가 생겨 전체 화면 안에서 도우미를 열 수 있습니다. 자세한 내용은 [AI 도우미](/help/ai-assistant) 장을 보세요.

### 글자 크기 바꾸기

도구 줄의 **A−** 단추와 **A+** 단추로 표의 글자 크기를 바꿉니다. 가운데 숫자 단추를 누르면 **기본 크기로** 돌아갑니다. 크기는 100%, 115%, 130% 세 단계이고, 이 컴퓨터의 브라우저에 저장됩니다. 다른 컴퓨터에서 열면 기본 크기로 보입니다.

## 작업 상세 패널 열기

한 작업의 자세한 내용은 화면 오른쪽 상세 패널에서 봅니다.

1. **작업명** 칸에서 작업 이름을 누릅니다. 키보드로는 이름 칸을 고른 상태에서 Enter를 누릅니다.
2. 화면 폭에 따라 오른쪽에 나란히 열리거나 화면 위에 겹쳐 열립니다.
3. 같은 이름을 다시 누르거나 오른쪽 위 **닫기**(X)를 누르거나 Esc를 누르면 닫힙니다. 패널이 열린 채 다른 작업 이름을 누르면 그 작업으로 바뀝니다.

패널 왼쪽 가장자리를 끌면 폭을 바꿀 수 있고, 가장자리를 더블클릭하면 처음 폭으로 돌아갑니다. 패널 안은 위에서 아래로 다음 내용이 차례로 나옵니다.

- 머리: 계층 이름 배지, 개요 번호, 작업 이름(길면 두 줄까지만 보이고 마우스를 올리면 전체가 보입니다)
- **계획%**, **실적%**, **계획대비** 세 숫자 카드
- 개요: **진척**, **담당팀**, **계획 일정**, **가중치**, **산출물**
- **담당·단계**: 개인 담당자와 업무 흐름 단계 ([담당자와 담당 팀](#담당자와-담당-팀), [업무 흐름 단계와 승인](#업무-흐름-단계와-승인) 참고)
- **명세**: 접혀 있는 칸입니다. 누르면 우선순위, 참조, 수용 기준, 명세 본문이 펼쳐집니다. 일반 사용자는 읽기만 합니다.
- **작업 의존성**: 선행·후속 작업 ([일정과 선행 작업 확인하기](#일정과-선행-작업-확인하기) 참고)
- **추가 정보**: 프로젝트에서 추가 항목을 만들어 둔 경우에 나옵니다.
- **산출물 첨부**: 파일 목록
- **회의록 원문**: 회의록 문단에서 등록한 작업에만 나옵니다. 회의록 제목과 날짜, **2판** 같은 버전, 원문 발췌가 보이고, **원문 위치 보기**를 누르면 회의록이 그 문단 위치로 열립니다. 회의록 기능이 꺼진 프로젝트에서는 나오지 않습니다. ([회의와 회의록](/help/meetings-minutes#wbs로-등록하기) 참고)
- **변경 이력**: 어느 팀(권한)이 언제 무엇을 바꿨는지

관리자에게는 연필 단추와 **구조 편집** 칸이 더 보입니다.

### 변경 이력 읽기

**변경 이력**에는 가장 최근 3건만 먼저 나옵니다. 더 보려면 **3건 더 보기** 같은 단추를 누르고, 다시 줄이려면 **접기**를 누릅니다. 한 줄은 시각, 바뀐 항목, 이전 값, 화살표, 새 값, 바꾼 쪽(예: 설계팀 · 멤버처럼 팀 · 권한)으로 되어 있습니다. 사람 이름은 나오지 않고 최근 50건까지만 불러옵니다. 아직 기록이 없으면 **아직 변경 기록이 없습니다.**라고 나옵니다.

## 내 작업의 실적 입력하기

실적%는 작업을 얼마나 했는지를 0부터 100까지 숫자로 적는 값입니다. 입력하는 방법은 표에서 직접 칸을 고치는 방법과 보드에서 카드를 옮기는 방법이 있습니다. 여기서는 표에서 입력하는 방법을 설명하고, 보드는 [진행 보기에서 카드 옮기기](#진행-보기에서-카드-옮기기)에서 설명합니다.

### 실적을 입력할 수 있는 작업

- 하위 작업이 없는 가장 아래 작업만 입력할 수 있습니다. 윗줄은 자동 계산입니다.
- 일반 사용자는 우리 팀이 주관 또는 지원 팀으로 적혀 있는 작업만 입력할 수 있습니다.
- 내가 어느 팀인지는 프로젝트의 팀 구성에 등록된 대로입니다. 팀이 등록되어 있지 않으면 어떤 작업도 내 팀 작업이 되지 않으니 프로젝트 관리자에게 요청하세요. 팀 구성은 [팀 구성과 근태](/help/members-attendance) 장에서 볼 수 있습니다.
- 입력할 수 있는 칸은 마우스를 올리면 손 모양 커서로 바뀌고 **클릭하여 실적% 입력**이라고 나옵니다.

### 입력하는 순서

1. **표**를 엽니다. 다른 보기라면 먼저 **표**를 누릅니다.
2. **실적%** 열에서 내 팀 작업의 칸을 누릅니다. 열이 안 보이면 **담당~계획% 펼치기** 단추를 누르세요.
3. 숫자 입력칸이 열리고 현재 값이 선택된 상태입니다. 새 숫자를 그대로 치면 옛 값이 덮어씌워집니다. 0부터 100 사이의 숫자를 넣습니다.
4. Enter를 누르면 저장하고 아래 줄의 같은 칸으로 이동합니다. Tab을 누르면 저장하고 오른쪽 칸으로, Shift+Tab은 왼쪽 칸으로 이동합니다. 다른 곳을 누르는 것도 저장입니다. 저장하지 않고 닫으려면 Esc를 누릅니다.
5. 저장되면 윗줄의 실적%, 상태, 막대가 함께 다시 계산됩니다.

저장 성공을 알리는 별도의 큰 안내는 없습니다. 대신 화면 맨 위 줄 오른쪽의 상태 표시가 **저장 중...** 으로 바뀌었다가 **동기화됨**으로 돌아옵니다. **저장 전 변경 1**이 나오면 아직 저장하지 않은 입력이 있다는 뜻이고, **확인 필요 1**이 나오면 저장되지 않았거나 충돌한 변경이 있다는 뜻입니다.

> **팁** 칸을 고른 상태에서 숫자 키를 바로 누르면 입력이 시작되고 그 숫자가 첫 글자가 됩니다. Enter나 F2로도 입력을 시작할 수 있습니다.

### 입력할 때 나오는 안내

| 안내 | 뜻과 해결 |
| --- | --- |
| **빈 값은 입력할 수 없습니다** | 실적%는 비울 수 없습니다. 0을 입력하세요. |
| **숫자만 입력하세요** | 숫자가 아닌 글자가 들어 있습니다. |
| **0~100 범위로 입력하세요** | 범위를 벗어났습니다. |
| **저장 권한이 없습니다(담당 팀·관리자만 입력 가능)** 또는 **담당 작업이 아님** | 우리 팀이 담당이 아닌 작업입니다. 입력하는 사이에 담당 팀이 바뀐 경우에 나옵니다. |
| **저장했습니다 — 선행 작업 2건이 아직 끝나지 않았습니다** | 저장은 되었지만 앞서 끝나야 할 선행 작업이 남아 있다는 알림입니다. 막지는 않습니다. |

### 완료 처리가 막히는 경우

다음 경우에는 99%까지만 입력할 수 있고 완료(100%)는 승인으로 처리합니다.

- 에이전트에게 맡긴 작업(위임됨, 작업 중, 검수 대기): **완료는 승인 버튼으로 처리합니다 — 에이전트 관할 작업(위임됨·작업 중·검수 대기)은 99% 까지 입력할 수 있습니다. 직접 완료하려면 위임을 끄세요.**
- 승인 단계가 둘 이상인 프로젝트의 업무 흐름 대상 작업: **이 프로젝트는 승인 단계가 둘 이상이라 완료(100%)는 단계 승인으로만 됩니다 — 99% 까지 입력할 수 있습니다.**

승인에 대해서는 [업무 흐름 단계와 승인](#업무-흐름-단계와-승인)을 보세요.

## 입력이 겹치거나 막힐 때

### 다른 사람이 먼저 고쳤을 때

내가 값을 고치는 사이에 다른 사람이 같은 칸을 먼저 바꾸면 **다른 사용자가 먼저 바꿨습니다**라는 창이 뜹니다. 창에는 **내 값**, **서버의 현재 값**, **편집을 시작할 때 값**이 나란히 나옵니다. 세 가지 중 하나를 고릅니다.

- **내 값으로 저장**: 방금 확인한 현재 값을 기준으로 내 값을 한 번 더 저장합니다.
- **서버 값 받기**: 내 입력을 버리고 현재 값을 받습니다.
- **계속 편집**: 아무것도 정하지 않고 입력 칸으로 돌아갑니다. Esc도 같은 동작입니다.

입력하는 동안 다른 사람이 같은 작업 줄의 값을 바꾸어 화면에 반영되어도 내가 입력 중인 값은 지워지지 않습니다. 이때 화면 맨 위 줄의 상태 표시에 **확인 필요 1**이 나타납니다. 저장할 때 내가 고치던 칸의 값이 실제로 달라져 있으면 위의 비교 창이 뜹니다.

### 저장 결과를 알 수 없을 때

저장 요청의 응답이 오지 않으면 화면이 다시 한 번 서버 값을 읽어 확인합니다. 그래도 알 수 없으면 **저장 결과를 확인하지 못했습니다. 입력은 그대로 있습니다 — 다시 저장하면 반영 여부부터 확인합니다.** 라고 나옵니다. 입력은 지워지지 않았으니 다시 저장하면 됩니다. 저장되지 않은 것이 확인되면 **저장되지 않았습니다. 입력은 그대로 있습니다 — 다시 저장하세요.** 가 나옵니다.

## 방금 입력 되돌리기

1. 칸에 입력 중이 아닌 상태에서 Ctrl+Z(맥에서는 ⌘+Z)를 누릅니다.
2. 가장 최근에 저장이 확인된 **실적%** 또는 **가중치** 입력이 이전 값으로 돌아갑니다.

되돌리기는 이 화면을 연 동안 내가 입력한 값만 대상입니다. 화면을 새로 고치면 기록이 사라집니다. 그 사이에 다른 사람이 같은 값을 바꿨다면 되돌려지지 않으며, 이때는 별도의 안내가 나오지 않습니다. 되돌린 뒤에는 값이 실제로 바뀌었는지 눈으로 확인하세요.

## 산출물 쓰고 파일 붙이기

산출물은 작업의 결과물입니다. 이름 한 줄과 첨부 파일로 적습니다.

### 산출물 글자 고치기

1. 작업 이름을 눌러 상세 패널을 엽니다.
2. 개요의 **산출물** 옆에 연필 단추가 있으면 누릅니다. 우리 팀이 담당인 가장 아래 작업(관리자는 모든 작업)에만 보입니다.
3. 입력칸에 결과물 이름을 적습니다. 입력칸에는 **예: 업무분장표**라는 안내 글자가 보입니다.
4. **저장**을 누르거나 Enter를 누릅니다. 취소하려면 **취소**나 Esc를 누릅니다.

산출물이 없으면 **없음**으로 보입니다. 다른 사람이 먼저 고쳤다면 같은 비교 창이 뜹니다.

### 파일 붙이기

1. 상세 패널의 **산출물 첨부**에서 **파일 추가**를 누르고 파일을 고릅니다. 우리 팀이 담당인 작업(관리자는 모든 작업)에서만 이 단추가 보입니다.
2. 올리는 동안 **처리 중…** 으로 바뀝니다. 끝나면 파일 이름과 크기가 목록에 나옵니다.
3. 파일을 지우려면 줄 끝의 휴지통 단추(**첨부 삭제**)를 누릅니다.

첨부가 없으면 **첨부된 파일이 없습니다. 파일을 추가하세요.** (올릴 수 있는 경우) 또는 **첨부된 파일이 없습니다.** 가 나옵니다.

### 파일 내려받기

파일 이름이 파란 글씨 링크로 보이면 눌러서 새 창에서 열 수 있습니다. 링크는 눌렀을 때 잠깐만 유효합니다. 이름이 링크가 아니라 검은 글씨라면 내려받을 권한이 없는 것입니다. **다운로드는 담당 팀과 관리자만 할 수 있습니다.** 라는 안내가 함께 나옵니다.

## 일정과 선행 작업 확인하기

### 일정 보기

상세 패널의 **계획 일정**에 시작일 ~ 종료일이 나옵니다. 일정을 고치는 일은 프로젝트 관리자만 합니다. 일정을 옮기고 싶으면 관리자에게 요청하세요.

### 선행 작업 보기

선행 작업은 이 작업보다 먼저 끝나거나 시작해야 하는 작업입니다. 상세 패널의 **작업 의존성** 칸을 보세요.

1. 칸 제목을 누르면 접고 펼 수 있습니다. 기본은 펼쳐져 있습니다.
2. 오른쪽 **목록**과 **그래프** 단추로 보기를 바꿉니다. 처음에는 **그래프**입니다.
3. **그래프**에서는 가운데 이 작업, 왼쪽에 선행 작업, 오른쪽에 후속 작업이 나옵니다. 다른 작업을 더블클릭하면 그 작업의 상세로 이동합니다. 많으면 **+3개 더**처럼 줄여 보이고 **접기**로 줄일 수 있습니다.
4. **목록**에서는 **선행 작업**과 **후속 작업**이 따로 나옵니다. 이름을 누르면 그 작업으로 이동하고, 접힌 줄에 있어도 자동으로 펼쳐서 보여 줍니다.

각 줄에 다음 표시가 붙습니다.

- **FS**, **SS** 배지: 연결 방식입니다. 마우스를 올리면 **완료 후 시작(FS)** 또는 **동시 시작(SS)** 이라고 나옵니다. +2처럼 숫자가 붙으면 대기 영업일입니다.
- **충족**, **대기**, **확인 불가**: 선행 작업이 조건을 채웠는지입니다.
- **가져옴**: 개발 도구나 에이전트가 계획 파일을 통째로 올릴 때 함께 들어온 연결입니다. 화면에서는 지울 수 없습니다.

맨 위에는 요약 배지가 하나 나옵니다.

- **선행 충족 — 시작 가능**: 모든 선행이 끝났습니다.
- **선행 2건 대기 중**: 아직 끝나지 않은 선행이 있습니다.
- **선행 1건을 확인할 수 없음**: 연결된 작업을 찾지 못했습니다.
- **이미 착수함**: 이미 시작한 작업입니다.

**지연 반영 예상 일정**이 계획과 다르면 상자에 예상 시작일 ~ 종료일과 **+2영업일** 같은 지연 일수가 나옵니다. 실적에 기댄 추정이면 **실적 기반 추정**이 함께 나옵니다. 선행 작업을 새로 잇는 일(**선행 추가**)은 관리자만 합니다.

## 담당자와 담당 팀

작업에는 두 가지 담당이 있습니다.

- **담당팀**: 작업을 맡은 팀입니다. 주관(●) 팀과 지원(△) 팀이 있고, 실적과 산출물을 고칠 수 있는 범위가 이 팀으로 정해집니다.
- **담당자**: 개인 담당자입니다. 업무 흐름에서 누가 단계를 바꾸고 승인할 수 있는지를 정하는 기준이 되기도 합니다.

상세 패널 **담당·단계** 칸의 **담당자**에는 지정된 사람 이름이 나옵니다. 지정되어 있지 않으면 **담당자 없음**입니다. 일반 사용자에게는 읽기만 되며 **보기 전용 — 프로젝트 관리자만 변경할 수 있습니다.** 라는 안내가 나옵니다. 담당자를 바꾸는 일은 프로젝트 관리자가 합니다.

한 작업을 담당 팀별로 나눠 둘 수 있습니다. 나눈 줄은 상세 패널 머리에 **팀 분담** 표시가 붙고, 표에서는 윗줄 이름을 빼고 앞에 └ 표시를 붙인 팀 부분만 보입니다.

## 업무 흐름 단계와 승인

업무 흐름은 작업이 아래 다섯 단계를 거쳐 끝나도록 관리하는 방식입니다. 하위 작업이 없는 가장 아래 작업 중에서 상세 패널의 **개발 워크플로 대상**을 켠 작업에만 적용됩니다. 단계 이름은 프로젝트에서 바꿀 수 있고, 기본 이름은 다음과 같습니다.

| 순서 | 기본 이름 | 뜻 |
| --- | --- | --- |
| 1 | **미착수** | 아직 단계가 정해지지 않았습니다. |
| 2 | **할당됨** | 담당자가 정해졌습니다. |
| 3 | **작업 중** | 일을 하고 있습니다. |
| 4 | **검수 대기** | 일을 마치고 확인을 기다립니다. |
| 5 | **완료** | 승인까지 끝났습니다. 실적이 100%가 됩니다. |

표의 **단계** 열에는 영문 두 글자 표시(AS, IP, IM, XX)로 나옵니다. 마우스를 올리면 전체 이름이 보입니다. 이 열은 **진척** 열과 다른 축입니다. 진척은 실적과 일정으로 계산되는 상태이고, 단계는 사람이 옮기는 값입니다. 그래서 검수 대기 중인 작업은 일은 끝났지만 실적이 아직 100%가 아니라서 **진행중**이나 **지연**으로 보일 수 있습니다. 둘이 어긋나 보여도 오류가 아닙니다.

### 단계를 바꾸고 승인할 수 있는 사람

- 단계를 직접 바꾸는 일: 프로젝트 관리자, 또는 그 작업의 상위 작업에 담당자로 지정된 사람입니다. 상세 패널의 **단계** 선택칸은 관리자에게만 열려 있고, 그 밖의 사람은 현재 단계를 읽기만 합니다.
- **개발 워크플로 대상** 체크: 같은 자격의 사람이 켜고 끕니다. 그 외에는 체크 상자가 회색으로 막혀 있습니다.
- 승인: 관리자, 또는 상위 작업의 담당자입니다. 관리자가 아닌 사람은 내가 그 작업의 담당자이거나 내가 착수한 작업을 스스로 승인할 수 없습니다. 이럴 때는 다른 관리자나 상위 담당자에게 요청합니다. 승인자가 관리자로만 정해진 단계는 관리자만 승인합니다.

### 승인하는 방법

1. 작업이 **검수 대기**인지 확인합니다.
2. 작업 상세 패널의 **담당·단계** 칸에 승인 단추가 보입니다. 프로젝트 관리자와 상위 작업 담당자에게 보입니다. 다만 관리자만 승인하도록 정해진 단계이거나 내가 그 작업의 담당자이면, 눌러도 '자기 담당이거나 … 승인할 수 없습니다' 같은 안내와 함께 거절됩니다. 단추에는 **승인(1/2 · 내부 검토)** 처럼 몇 번째 단계인지와 단계 이름이 나옵니다. 단계가 하나뿐이고 따로 이름이 없으면 **승인(1/1 · 승인)** 으로 나옵니다.
3. 단추를 누릅니다. 마지막 단계까지 승인되면 작업이 **완료**가 되고 실적이 100%가 됩니다. 중간 단계면 **검수 대기**에 머물고 다음 승인자에게 알림이 갑니다.

화면이 보여 준 승인 단계가 그새 바뀌었다면 **승인 단계가 바뀌었습니다 — 새로 불러온 단계를 확인한 뒤 다시 승인하세요.** 가 나옵니다. 승인 단계가 둘 이상인 프로젝트에서는 단계 선택칸에서 **완료**를 직접 고를 수 없고 **승인 단계가 둘 이상이라 완료는 검수 대기에서 단계 승인으로만 됩니다.** 라는 안내가 나옵니다.

> **팁** 보드 카드의 **승인** 단추도 지금 차례인 단계로 승인을 요청합니다. 다만 몇 번째 단계인지는 단추에 나오지 않으니, 승인 단계가 여러 개인 프로젝트에서 어느 단계를 승인하는지 확인하고 싶으면 상세 패널의 승인 단추를 쓰세요. 승인 단계를 몇 개로 할지는 프로젝트 관리자가 설정합니다.

> **알아두기** 에이전트에게 맡긴 작업은 단계가 잠깁니다. **에이전트에 위임된 작업입니다. 단계는 승인·반려로 바뀝니다. 직접 바꾸려면 위임을 끄세요.** 라는 안내가 나옵니다. 에이전트는 [에이전트](/help/agents) 장에서 설명합니다.

## 보드로 보기

**보드** 보기는 작업 중 하위 작업이 없는 가장 아래 작업만 카드로 보여 줍니다. 카드를 어디에 놓는지는 위쪽 탭이 정합니다.

화면 위쪽 왼쪽에는 묶는 방식 탭이 있습니다.

- **진행**: **시작전**, **진행중**, **완료** 세 칸. 카드를 옮겨 진척을 바꿉니다.
- **흐름**: **미착수**, **할당됨**, **작업 중**, **검수 대기**, **완료** 다섯 칸. 업무 흐름 단계를 봅니다.
- 맨 위 계층 이름에 '별'이 붙은 탭: 예를 들어 맨 위 계층 이름이 '단계'이면 **단계별**입니다. 맨 위 계층 항목마다 한 칸입니다.
- **담당자별**: 담당 팀마다 한 칸과 **미배정** 칸입니다. 탭 이름은 담당자별이지만 칸은 주관 팀 기준으로 나뉩니다.

**단계별**과 **담당자별**은 보기 전용입니다. 이 두 탭에는 **이 뷰는 조회 전용입니다 — 진척 이동은 ‘진행’ 뷰에서 하세요.** 라는 안내가 나옵니다.

카드에는 위에서부터 다음이 보입니다.

- 맨 위 계층의 이름(작은 글씨). 예를 들어 '1. 준비' 아래의 작업이면 '1. 준비'가 보이고, 바로 위 윗줄 이름이 아닙니다.
- 작업 이름
- 계획 종료일. 지났으면 **지연 3일**처럼, 남았으면 **D-5**처럼 표시되고 오늘이 마감이면 **D-DAY**가 나옵니다.
- 진척 막대와 퍼센트
- 담당 팀 표시

카드 왼쪽 색 띠는 상태 색입니다. 한 칸 안에서는 지연된 카드가 위에 오고, 그다음 종료일이 빠른 순, 그다음 이름 순입니다. 카드 본문을 누르면 **표** 보기의 그 작업 줄로 이동합니다.

다른 사람이 카드를 옮기면 몇 초 안에 내 화면에도 반영됩니다.

### 진행 보기에서 카드 옮기기

내 팀이 담당인 작업의 카드(관리자는 모든 카드)에만 조작 단추가 보입니다. 처음 보드를 열면 **카드를 끌어 진척을 옮겨보세요** 안내가 나오고, **알겠어요**를 누르면 닫힙니다.

**진척 입력** 창을 쓰는 방법은 다음과 같습니다.

1. **시작전** 칸의 카드에서 **착수**를 누릅니다. 또는 카드를 **진행중** 칸으로 끕니다.
2. **진척 입력** 창이 열리고 **이 작업의 실적%를 선택하세요.** 라고 나옵니다. 10%, 30%, 50%, 70%, 90% 단추 가운데 하나를 누르거나, **직접 입력(1~99)** 칸에 숫자를 넣고 **적용**을 누릅니다. 1부터 99까지만 넣을 수 있고 아니면 **1~99 사이의 값을 입력하세요. 완료(100%)는 카드를 완료 칸으로 옮깁니다.** 라고 나옵니다.
3. **진행중** 카드에서는 **실적 10% 감소**, **실적 10% 증가** 단추(− , +)로 10%씩 조절하고 **완료**를 누르면 100%가 됩니다.
4. **완료** 카드에서는 **재개**를 누르면 같은 **진척 입력** 창이 열립니다.
5. 카드를 **시작전** 칸으로 끌면 **진척을 0%로 되돌릴까요?** 확인 창이 뜨고, **0%로 되돌리기**를 누르면 현재 진척이 사라지고 **시작전**으로 이동합니다. **취소**로 닫을 수 있습니다.
6. 카드를 **완료** 칸으로 끌면 바로 100%가 됩니다.

카드 아래 **이동** 단추를 눌러 나오는 목록에서 칸을 골라도 됩니다. 마우스를 쓰기 어려울 때 편합니다.

저장되는 동안 카드에 돌아가는 표시가 나옵니다. 저장에 실패하면 카드는 옮긴 자리에 둔 채 경고가 나옵니다. **원위치**를 누르면 되돌리고, **재시도**를 누르면 다시 저장합니다. 다른 사람이 먼저 바꿨다면 표에서와 같은 비교 창이 뜨고, 실패 안내로 **다른 사용자가 먼저 변경했어요. 새로고침 후 다시 시도하세요.** 가 나올 수 있습니다.

### 흐름 보기에서 단계 확인하기

**흐름** 탭에는 **흐름 뷰에서는 카드 이동 메뉴를 사용해 단계를 변경할 수 있습니다.** 라는 안내가 나옵니다. **검수 대기** 칸 제목 아래에는 승인 단계 요약이 나옵니다. 예를 들어 **1단계 승인 (검토)** 입니다.

- 카드의 **이동** 단추에서 단계를 고르면 단계가 바뀝니다. 이 단추는 단계를 바꾸거나 승인할 수 있는 사람의 카드에만 보입니다. 목록의 **완료**는 승인 단계가 하나뿐이고 내가 승인할 수 있는 작업에서만 나옵니다. 승인 단계가 둘 이상이면 완료는 **승인** 단추로만 됩니다.
- **검수 대기** 카드에는 **승인** 단추도 있습니다. 승인할 수 있는 사람에게만 보이며, 누르면 지금 차례인 단계로 승인을 요청합니다. 승인 대기 단계를 확인하지 못하면 "승인 대기 단계를 확인하지 못해 승인하지 않았습니다. 잠시 뒤 다시 시도하세요."라고 나오고 승인하지 않습니다. 누르는 사이 상태가 바뀌었으면 "그새 바뀌었습니다 — 최신으로 다시 그렸습니다"가 나옵니다. 승인 단계가 여러 개인 프로젝트에서 중간 단계를 승인하면 카드는 **검수 대기**에 남고, 화면 낭독 알림도 "승인 완료"가 아니라 "… 승인됨(1/2단계) — 다음 단계 승인을 기다립니다"처럼 단계 하나가 승인됐다고 알립니다.

단계를 바꾸고 승인하는 데에는 앞의 [단계를 바꾸고 승인할 수 있는 사람](#단계를-바꾸고-승인할-수-있는-사람)과 같은 자격이 필요합니다. 흐름 보기의 단추는 이 자격(프로젝트 관리자, 또는 그 작업의 상위 작업 담당자)이 있을 때만 보입니다. 프로젝트의 승인 단계 설정을 불러오지 못했을 때는 단계 수를 짐작하지 않고 **승인** 단추와 목록의 **완료**를 모두 숨깁니다(단계 이동은 그대로입니다). 새로고침해도 같으면 프로젝트 관리자에게 설정 확인을 요청하세요. 담당 팀에 속해 있다는 것만으로는 보이지 않고, 내가 담당자인 작업은 관리자가 아니면 승인 단추가 보이지 않습니다. 단추가 안 보이면 관리자나 상위 작업 담당자에게 요청하세요.

### 보드에서 필터와 검색 쓰기

보드 위쪽 줄에는 필터와 검색 도구가 있습니다.

- **내 팀** / **전체**: 우리 팀이 담당인 카드만 볼지 모두 볼지 고릅니다. 팀에 소속된 일반 사용자는 처음에 **내 팀**으로 시작하고, 관리자와 팀이 없는 사람은 **전체**로 시작합니다.
- **지연**, **이번 주 마감**, **진행중**, **미착수**: 빠른 필터 단추입니다. 여러 개를 켤 수 있습니다. **지연**과 **이번 주 마감**처럼 일정 쪽 단추를 여러 개 켜면 조건을 모두 만족하는 카드만 남습니다. **진행중**과 **미착수**는 함께 켜면 둘 중 하나에 해당하는 카드를 모두 보여 줍니다. 일정 쪽 조건과 진척 쪽 조건은 함께 만족해야 합니다. 단추에 마우스를 올리면 이 겹치는 방식이 안내로 나옵니다. **이번 주 마감**은 오늘부터 6일 뒤까지 종료인 카드이고, **미착수**는 실적이 0%인 카드입니다(**흐름** 탭의 **미착수** 칸은 업무 흐름 단계라서 다른 뜻입니다).
- **작업명·코드·담당 팀 검색**: 검색칸입니다. 작업 이름, 작업 코드, 담당 팀 이름(팀 코드 포함)으로 찾으며 사람 이름은 찾지 않습니다.

조건에 맞는 카드가 없으면 **필터에 맞는 작업이 없습니다 · 렌즈·필터·검색을 조정해 보세요.** 라고 나오고, 아예 작업이 없으면 **표시할 작업이 없습니다**가 나옵니다. 칸에 카드가 없으면 **작업 없음**(진행 보기에서는 **여기에 카드를 놓으세요**)이 나옵니다.

## 키보드로 표 다루기

**표**에서 칸을 한 번 눌러 고르면 마우스 없이 움직일 수 있습니다. 맥에서는 Ctrl 대신 ⌘를 씁니다.

| 키 | 하는 일 |
| --- | --- |
| 방향키 | 칸 하나씩 이동 |
| 작업명 칸에서 오른쪽 방향키 | 접힌 줄이면 펼침. 그렇지 않으면 오른쪽 칸으로 이동 |
| 작업명 칸에서 왼쪽 방향키 | 펼쳐진 줄이면 접음. 이미 접혔거나 하위가 없으면 윗줄로 이동 |
| Home, End | 그 줄의 처음 칸, 끝 칸 |
| Ctrl+Home, Ctrl+End | 표의 처음 칸, 끝 칸 |
| PageUp, PageDown | 한 화면만큼 위, 아래 |
| Enter 또는 F2 | 고칠 수 있는 칸이면 입력 시작. 작업명 칸에서는 상세 패널 열기 |
| 숫자 키 | 고칠 수 있는 칸에서 입력을 시작하며 그 숫자가 첫 글자 |
| 입력 중 Enter | 저장하고 아래 칸으로 |
| 입력 중 Tab, Shift+Tab | 저장하고 오른쪽 칸, 왼쪽 칸으로 |
| 입력 중 Esc | 저장하지 않고 닫기 |
| Ctrl+Z | 방금 저장한 실적%·가중치 되돌리기 |

관리자에게는 줄 선택 키도 있습니다.

| 키 | 하는 일 |
| --- | --- |
| 번호·작업명 칸에서 Space | 그 줄 선택 또는 선택 해제 |
| Shift+Space | 마지막으로 고른 줄부터 지금 줄까지 선택 |
| 번호·작업명 칸에서 Shift+위·아래 방향키 | 줄 범위 선택 |
| Ctrl+A | 보이는 줄 전체 선택 |
| Esc | 선택 해제 |

> **팁** Tab 키를 누르면 표 안에서 마지막으로 있던 칸으로 들어가고, 한 번 더 누르면 표 밖으로 나갑니다. 표 안에서는 방향키로 움직이세요.

## 여러 칸 복사하고 붙여넣기

엑셀처럼 여러 칸을 골라 복사하고 붙여넣을 수 있습니다.

### 범위 고르기

1. 번호·작업명이 아닌 칸(예: **계획시작**, **가중치**, **실적%**)을 한 번 눌러 고릅니다.
2. Shift를 누른 채 방향키를 누르면 범위가 늘고 줄어듭니다. Shift를 누른 채 다른 칸을 클릭해도 됩니다.
3. 범위에 든 칸이 연한 색으로 표시됩니다.
4. 범위를 풀려면 Esc를 누르거나 일반 방향키를 누릅니다.

### 복사하기

범위를 고르고 Ctrl+C를 누릅니다. 범위가 없으면 고른 칸 하나가 복사됩니다. 엑셀이나 메모장에 붙여넣으면 칸은 탭으로, 줄은 줄바꿈으로 구분됩니다. 조회 전용 사용자도 복사는 할 수 있습니다.

### 붙여넣기

1. 엑셀 등에서 복사한 칸이 클립보드에 있는 상태에서, 붙여넣기를 시작할 칸(범위가 있으면 범위의 왼쪽 위 칸)을 고릅니다.
2. Ctrl+V를 누릅니다.
3. 오른쪽과 아래로 복사한 크기만큼 값이 들어갑니다. 고칠 수 없는 칸은 건너뜁니다.

붙여넣을 수 있는 칸은 **산출물**(우리 팀이 담당인 가장 아래 작업), **실적%**(내가 입력할 수 있는 가장 아래 작업), 사용자 정의 추가 정보 일부이고, **계획시작**, **계획종료**, **가중치**는 관리자만 됩니다. **담당팀**, **담당자**, **진척**, **단계**, **계획%**, **계획대비** 칸은 값을 쓰지 않고 건너뜁니다. 하위가 있는 줄의 **실적%**는 자동 계산이라 건너뜁니다.

붙여넣기 결과는 칸 수가 적으면 **12개 셀 붙여넣음**처럼 조용히 알려 주고, 건너뛴 칸이 있으면 **3칸 건너뜀**이 같은 줄에 붙습니다. 칸이 많거나 문제가 있으면 창이 열립니다.

- 200칸을 넘는 붙여넣기는 적용 전에 **붙여넣기 확인** 창에서 **바로 저장되고 한꺼번에 되돌릴 수 없습니다.** 라는 설명과 함께 **250개 셀에 적용** 같은 단추를 눌러야 합니다.
- 한 번에 2000칸까지만 바꿀 수 있습니다. 넘으면 **한 번에 2000칸까지 바꿀 수 있습니다. 나누어 적용해 주세요.** 가 나옵니다.
- 결과 창에는 바꾼 칸, 이미 같은 값, 건너뜀(편집할 수 없는 칸, 값이 맞지 않음), 표 밖으로 넘쳐 버림, 충돌, 저장하지 못함이 나뉘어 보입니다. 충돌한 칸은 쓰지 않으니 최신 값을 확인한 뒤 필요한 칸만 다시 붙여넣으세요.

### 칸 지우기

범위를 고른 뒤 Delete 또는 Backspace를 누르면 범위 안에서 고칠 수 있는 칸을 비웁니다. 20칸을 넘으면 **지우기 확인** 창이 뜹니다. 실적%는 비울 수 없는 칸이라 건너뜁니다.

> **주의** 붙여넣기와 지우기는 칸마다 바로 저장되고 한꺼번에 되돌리는 기능이 없습니다. 먼저 Ctrl+C로 원래 값을 복사해 두면 안전합니다.

## 주간 보고서 내려받기

도구 줄의 문서 모양 단추(넓은 화면에서는 **주간보고** 글자, 마우스를 올리면 **주간보고서 생성**)를 누르면 **주간 보고서** 창이 열립니다. 이 창에는 전체 진척, 맨 위 계층별 계획·실적·차이·상태, 지연 작업, 팀별 현황이 표로 정리되어 있습니다.

창 아래의 **Excel**과 **PPT** 단추로 파일을 내려받을 수 있습니다. 주간보고 기능이 꺼져 있으면 내려받기가 되지 않습니다. 주간보고 기능은 [주간보고](/help/weekly) 장에서 설명합니다. **AI 코멘트 포함**을 체크하면 PPT 마지막에 AI 종합 코멘트 장이 붙습니다. 그러려면 신선한 AI 브리핑이 있어야 하며, 브리핑 생성(**AI 브리핑 생성**)은 프로젝트 관리자만 할 수 있습니다.

## 엑셀로 내려받기와 가져오기

작업 계획 전체를 엑셀 파일로 내려받는 단추와 엑셀 파일로 작업을 가져오는 마법사는 프로젝트 관리자용 화면에 있습니다. 작업 계획 화면에는 이 단추가 없습니다.

- 내려받기: 프로젝트 설정의 **WBS 데이터 가져오기 · 내보내기** 칸에 있는 **Excel 내보내기** 단추입니다.
- 가져오기: 같은 칸의 **가져오기 마법사 열기**입니다. 일반 사용자가 가져오기 화면에 들어가면 **임포트 권한이 없습니다**와 **프로젝트 관리자만 임포트 마법사를 사용할 수 있습니다.** 라는 안내만 나옵니다.

일반 사용자가 엑셀 파일이 필요하면 프로젝트 관리자에게 요청하세요. 방법은 [프로젝트 관리자 안내](/help/project-admin)에서 설명합니다. 작업이 하나도 없는 프로젝트에서 관리자가 표를 열면 **작업 추가**와 **엑셀로 가져오기** 단추가 나옵니다.

## 관리자에게만 보이는 것

일반 사용자 화면에는 없지만 관리자 화면에서 보이는 기능입니다. 함께 일하는 관리자와 이야기할 때 참고하세요.

- 화면 맨 위 오른쪽의 **작업 추가** 단추: 맨 위 계층 작업을 새로 만듭니다. 입력칸에 이름을 적고 **추가**를 누릅니다.
- 줄 앞의 체크 칸과 화면 아래에 뜨는 대량 작업 바: 여러 줄을 골라 **대량 수정**이나 **붙여넣기**를 합니다.
- 상세 패널의 연필 단추, **구조 편집**(**하위 추가**, **팀 분담 항목 추가**, 위·아래 이동, **삭제**), **선행 추가**, 단계 선택칸, **담당자** 선택칸.
- 가중치 칸, 날짜 칸을 고치는 일, 간트 막대를 끌어 일정을 옮기는 일.

막대를 끌어 놓으면 **간트 일정 변경 검토** 창이 뜨고 원래 일정과 바뀔 일정, 선행·후속 작업에 미치는 영향이 나옵니다. **일정 변경 적용**을 눌러야 저장되며, 연결된 작업의 일정은 자동으로 따라 움직이지 않습니다.

## 문제가 생길 때

### 실적% 칸을 눌러도 입력칸이 열리지 않아요

다음 중 하나입니다.

- 하위 작업이 있는 윗줄입니다. 가장 아래 작업을 찾아 입력하세요.
- 우리 팀이 담당(주관·지원)이 아닌 작업입니다. **담당팀** 열을 확인하세요.
- 내가 조회 전용입니다. 프로젝트 관리자에게 권한을 요청하세요.
- **간트** 보기입니다. **표**를 누르세요.

### 보드 단추가 없어요

프로젝트나 워크스페이스에서 칸반 기능이 꺼져 있습니다. 프로젝트 관리자에게 요청하세요.

### 담당자 열이나 단계 열이 안 보여요

**담당자** 열은 담당자가 지정된 작업이 하나라도 있어야, **단계** 열은 에이전트에게 맡긴 작업이 하나라도 있어야 나타납니다. 또 열 숨김 상태(눈 모양 단추)가 아닌지 확인하세요. **담당자** 열은 간트 보기에는 나오지 않지만 **단계** 열은 간트 보기에도 나옵니다.

### 100%를 넣을 수 없어요

에이전트에게 맡긴 작업이거나 승인 단계가 둘 이상인 프로젝트입니다. [완료 처리가 막히는 경우](#완료-처리가-막히는-경우)를 보세요.

### 화면 값이 방금 고친 것과 달라요

화면 맨 위 줄의 **연결 끊김** 표시가 있는지 보세요. 연결이 끊겨 있으면 새로 고친 뒤 다시 시도하세요. 다른 사람이 먼저 고쳤을 수도 있으니 **변경 이력**을 확인하세요.

### 표 위에 설정 오류 안내가 나와요

프로젝트 설정 일부를 읽지 못했다는 뜻입니다. 관리자에게는 설정으로 가는 링크가 함께 보입니다. 일반 사용자는 관리자에게 알려 주세요.
