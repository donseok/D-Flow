# LLM 대화 문체 (압축)

- 목적: 뜻 유지 + token 최소
- 사람 읽는 문서 = `Korean-STE-Writing-Guide.md`

## 언어

- 뼈대 한국어. tech term·identifier·code는 영어 원문 (`cache`, `migration`, `job`, `DB`)
- 적용: 스킬 문서, 레인 보고(레인 → 조정자), 정본 메모, 마감 보고, memory 파일
- 전부 영어 허용: 레인 지시(조정자 → 레인), subagent 지시문·결과, 검색 agent 지시, 중간 메모·scratchpad 파일
- 제외: 사용자 답변(사람용 문서), commit 메시지·repo 문서(repo 관례)
- [필수] 프로토콜 고정 문구는 영어 글 안에서도 원문 그대로: `진행 보고:`, `머지 요청:`, `머지 허가:`, `대기:`, `머지 완료:`, `정리 완료:`, `측정 시작:`, `측정 끝` (스크립트가 문구로 판별)

## 우선순위

- 사용자 답변 = 출력 스타일(fluent-korean) + 사람용 문서. 이 문서 적용 안 함
- 그 밖의 위 적용 대상 = 이 문서. 다른 말투 지시(caveman 등)보다 우선

## 용어

- 한 대상 한 단어. 아래 영어로 통일
- 예약 작업 = job, 실행 이력 = run history, 재기동 = restart, 기동 = start, 중지 = stop
- 레인 = lane, 조정자 = coordinator, 머지 = merge, 워크트리 = worktree
- 시험 = test, 빌드 = build, 배포 = deploy, 커밋 = commit, 브랜치 = branch
- 마이그레이션 = migration, 컬럼 = column, 주석 = comment, 권한 = permission, 화면 = screen
- 도메인 고유명(MCM, MDM, PDB, L_MAIN, Flyway)은 원문

## 압축

- 조사 생략: `이/가`, `을/를`, `의`, 대조 아닌 `은/는`
- 뜻 정하는 조사 유지: `에`, `에서`, `으로`, `까지`, `부터`, `만`, `도`, `보다`
- 생략해 두 뜻 되면 유지
- 종결 생략, 명사로 끝냄: `재기동 필요`, `멈춤`
- 인사·맺음·질문 되풀이·군말 금지. 결론 첫 줄
- 기호: `→` 순서·결과, `·` 나열, `=` 같음, `≠` 다름
- 범위 `-` (`~` 금지)
- 번역투 금지 (영어 구조 직역):
  - `에 있어서` → `에서`, `필요로 하다` → `필요`, `을 통해` → `으로`, `에 대해` → `을`
  - `하는 것이 가능하다` → `할 수 있음`, `할 필요가 있다` → `해야 함`, `이 존재하다` → `있음`
  - `을 가지고 있다`(have) → `있음`, `에 의해 ~되다` → 행위자 주어 능동
  - `만약 ~라면` → `~면`, `~하는 것이다` → `~함`, `가장 ~한 것 중 하나` 금지
- markdown 강조·표 최소. 짧은 bullet

## 구조

- 한 줄 한 동작
- 조건 먼저: `필수 칸 다 채우면 Save`
- 순서 → 번호 목록 또는 `A → B → C`
- 한 대상 한 단어

## 정보 보존 [필수]

- 숫자·단위·identifier·code·고유명사 원문 그대로
- 부정·금지는 말로 명시 (`금지`, `안 함`). 압축 중 누락 금지
- 확신 수준 유지: 추정 = `추정`, 확인 못 함 = `미확인`
- 원문에 없는 수치·원인·날짜 생성 금지
- 압축해 뜻 바뀌면 압축 안 함

## 예

- `MCM을 내리면 모듈의 예약 작업이 멈춥니다.` → `MCM 내리면 module job 멈춤`
- `필수 칸을 모두 채웠으면 저장 버튼을 누르세요.` → `필수 칸 다 채우면 Save`
- `원인은 락 경합일 수 있으나 확인하지 못했습니다.` → `원인 lock contention 추정, 미확인`
- 사람 안 읽는 글: `cause: lock contention (guess, unverified)`
