# SP4 Phase B — 팀 색·화면 원천·화면 이행·마감 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 팀 화면 색을 `category-N` 슬롯(생성 순 팔레트 자리, 밖이면 팀 id 해시)으로 바꾸고, 범위 레이아웃 셋·명단·개요가 요청 범위 팀 원천을 쓰게 해 옛 팀 캐시(`src/lib/teams/master.ts`)를 지우며, D52 의 화면(팀 개명 입력·팀 색 칩·'공용 팀 전환'·#23 실행 ID·영수증·#25 주간 채움형·색 토큰·가중치 미지정·토스트 사전)을 끝내고 SP4 를 마감한다 — 체크포인트 B(로컬 태그 `sp4-done`).

**Architecture:** 두 브랜치를 쌓아 한 번에 반영한다(스펙 D1·§2.1). `ui/sp4-teams`(묶음 B-1) = 슬롯 함수 → 소비처 12파일 → `teamStyle`·별칭 삭제 → 레이아웃 원천 → 캐시 삭제. `ui/sp4-screens`(B-2~B-5, `ui/sp4-teams` 위) = 팀 화면 → 가져오기·WBS·칸반 화면 → 주간 → 마감. **마이그레이션은 없다**(D3 — `teams.color` 그대로, 전환 RPC 는 A1 의 것) — 훅 G1·G4 대상 아님. 화면 판정의 근거는 행위 테스트이고 UI 위험 파일의 깨짐은 마감의 E2E `teams-color-render`·눈확인 B 행이 본다(CLAUDE.md — 빌드·테스트로 안 잡힌다).

## 계획 판정(구속 — 구현자가 바꾸지 않는다. 스펙의 빈칸·UI-2 현실과 어긋난 곳을 이 계획이 정한 곳)

- **P0 착수 대조(Step 0).** 과제마다 Step 0 이 그 과제가 고치는 심볼을 `grep` 으로 대조한다. 계획이 가정한 모양(이름·인자·줄의 내용)과 다르면 **멈추고 보고**한다 — 계획 코드를 현행에 억지로 맞추지 않는다. 줄 번호만 다른 것은 그대로 진행한다(레인 B 과제 39 가 아직 같은 파일을 만진다).
- **P1 팀 슬롯 규칙(D3).** `teamSlot({ id, color })` = `TEAM_PALETTE.indexOf(color.trim().toLowerCase())` 가 0 이상이면 `category-(i+1)`, 아니면 `category-(hash(id) % 8 + 1)`(hash = 31 곱 누적 `>>> 0`, 옛 `teamStyle` 과 같은 식을 **id** 에). 클래스는 리터럴 여덟 벌(`fg`·`bar`·`chip`). **code 로 찾을 때는 `teamSlotFor(code, teams)`** — 주어진 팀 목록(그 범위의 활성 팀)에 그 code 가 없으면 **중립 슬롯 `NEUTRAL_SLOT`**(`text-neutral`·`bg-neutral`·`bg-neutral-weak text-neutral`). 이유: 목록 밖 code(비활성 팀 담당·워크스페이스 회의록의 프로젝트 전용 팀·공유 회의록)를 code 해시로 칠하면 같은 팀이 화면마다 다른 색이 된다. 채움(`bar`) 위 글자는 지금처럼 `text-category-fg`(라이트 흰색·다크 cobalt-950 — `bg-neutral` 위에서도 대비가 선다).
- **P2 소비 경로.** 클라이언트는 `TeamsProvider` 의 새 훅 `useTeamSlot(): (code: string) => TeamSlotStyle`(그 범위의 활성 팀으로 `teamSlotFor`), 서버 컴포넌트(`TeamProgress`)는 `DashboardView` 가 이미 넘기는 `teams` 로 `teamSlotFor`. `OwnerBadges` 는 서버 컴포넌트(`DelayAging`·`VarianceRanking`)도 그리므로 **새 `'use client'` 파일 `src/components/wbs/OwnerBadges.tsx` 로 옮기고 `shared.tsx` 가 다시 내보낸다**(import 줄은 그대로). 공유 회의록(`/share/minutes/[token]`)은 `(app)` 밖이라 공급자가 없다 — 훅이 빈 목록을 보고 중립으로 그린다. 공유 페이지의 반환 컬럼 화이트리스트는 넓히지 않는다(색 하나 때문에 공개 경로의 조회를 늘리지 않는다).
- **P3 레이아웃 원천(D19·Q23, UI-2 현실).** UI-2b 뒤 팀을 싣는 레이아웃은 **셋**이다 — `(global)`·`w/[slug]` = `workspaceTeams(wid)` 의 활성, `p/[projectId]` = `projectTeams(pid)` 의 활성(스펙은 둘로 적었다 — `(global)/layout.tsx` 는 UI-2b 가 더한 범위 레이아웃). 읽기는 `loadShell` 과 **병렬**(새 직렬 왕복을 만들지 않는다). 실패는 **`unstable_rethrow(e)` 다음 로그 + 빈 목록**으로 셸을 그린다 — UI-2 가 테스트로 고정한 계약("설정·임포트 같은 복구 화면까지 오류가 되지 않게", `tests/ui/app-layout-teams.test.tsx` 머리)을 지킨다. 팀으로 판정하는 화면(명단 편집·설정 팀 절·가져오기)은 자기 원천 호출에서 실패를 드러낸다(명단 페이지·`DashboardView` 는 던진다, 설정은 `ERR_TEAMS_UI`, 가져오기는 503). 열화(actor null)면 읽지 않고 빈 목록(지금 그대로). 공용 도우미 `activeTeamsForLayout`(`src/lib/teams/layoutTeams.ts`)이 셋을 같은 꼴로 만든다.
- **P4 칸반 도메인.** `groupByOwner(items, teams: readonly TeamCode[], colorTeams: readonly TeamColorRef[] = [])` — `accentDot = teamSlotFor(team, colorTeams).bar`. 화면(`KanbanBoard`)은 `useTeams()` 를 넘기고, 봇 도구(`src/lib/ai/tools/kanban.ts`)는 넘기지 않는다(색을 그리지 않는다 — 중립). `KanbanColumn.accentDot` 의 클래스 문자열 계약은 그대로다.

- **P6 `copyGlobalTeams` → 전환 RPC(T14·스펙 §3.3 ⑦).** 결과 계약 `{ ok: true } | { ok: false; error }` 그대로. `converted` 이고 `teams > 0` = 성공, `converted` 이고 `teams === 0` = `'복사할 전역 팀이 없습니다.'`, `already` = `'이미 프로젝트 팀이 정의되어 있습니다.'`, RPC 오류 = `rpcFailure` 자기 표(`TEAM_CONVERT_FORBIDDEN` → `ERR_DENIED`, `PROJECT_NOT_FOUND` → `ERR_MISSING`) 다음 55P03·40P01 은 그 고정 문구(재시도), 나머지는 `failWith(…, ERR_TEAM_COPY)`. 모양이 어긋난 결과(`status` 가 둘 다 아님)도 `failWith`. `p_actor` = `g.actor.userId`(D51 (a)). 확인 문구·성공 토스트·"전역 팀을 상속" 문구 정정은 같은 커밋(스펙 §5.2).
- **P7 "전역 팀을 상속" 문구(SP3a §10).** 화면의 "전역 팀" → "공용 팀"(워크스페이스 공용 팀 — SP2 이후의 낱말). 대상: `ProjectTeamsManager.tsx` 의 문구 전부와 **설정 페이지 팀 절의 설명 한 문장**(`p/[projectId]/settings/page.tsx` — "정의하지 않으면 전역 팀을 상속합니다."·영문 "Inherits global teams"). 버튼 이름은 '공용 팀 전환으로 시작'(스펙 §7 B 의 '전역 팀 복사로 시작'과 같은 버튼). 스펙 §2.3 이어 고침 표는 "설정 페이지는 B 에서 바뀌지 않는다"고 적었지만, 그 문장과 개명 입력에 필요한 팀 행 매핑(`name`·`color`)이 그 파일에 있다 — 이 둘만 고친다.
- **P8 개명 입력(D37·D52).** 표의 '팀' 칸 = `name`(그리고 `name ≠ code` 면 옆에 보조 글씨 `code`) + 연필 버튼 → 그 행 안 입력(최대 40자, Enter 저장·Esc 취소). 클라이언트는 공백만 걸러 `'팀 이름을 입력하세요.'` 를 보이고 나머지 규칙(길이·예약어·겹침)은 서버 문구를 그 행 아래 `role="alert"` 로 보인다. 성공은 토스트 + `router.refresh()`. 팀 색 칩 = `teamSlot(row).chip` 의 작은 견본(공용 팀 관리 #15 만 — 명단 칩은 SPU3).
- **P9 #23 영수증 화면.** 결과 카드에 '실행 ID' = `commandId.slice(0, 8)`(전체는 `title`)와 링크 `?receipt=<commandId>`('실행 기록 보기'). 가져오기 페이지가 `searchParams.receipt` 를 읽어 관리자이면 `getImportReceipt(projectId, receipt)` 를 부르고 새 `ImportReceiptPanel` 이 그린다 — 찾음: 모드·건수·시각·실행 ID, `receipt: null`: `StatusMessage kind="empty"`, 실패: `kind="partial_error"`, uuid 아님: 액션을 부르지 않고 `kind="empty"`(주소가 올바르지 않음). 중복 결과(`kind: 'duplicate'`)는 결과 카드 위 `StatusMessage kind="conflict"`. 단계 표시 = `<ol aria-label>` 세 단계(파일 선택·확인/실행·결과), 활성 단계 `aria-current="step"`, 각 단계 앞 `n/3`.
- **P10 #25 주간 채움형.** `ProjectPageShell variant="fill"`. `WeeklySheetView` 의 세 갈래 루트를 `flex h-full min-h-0 flex-col gap-3` 로, 주 이동 줄(`WeekNav` 루트)은 `shrink-0`(sticky·`top-(--frame-sticky-top)`·`bg-canvas/95`·`backdrop-blur-sm` 를 뗀다 — 채움형에서 main 은 스크롤하지 않는다), 시트 상자 `isolate overflow-x-auto` → `isolate min-h-0 flex-1 overflow-auto`. 주 이동 링크 줄(`<Link href=…>`)은 손대지 않는다(SP5 A 가 같은 줄을 `prevWeek`/`nextWeek` 로 바꾼다 — 겹침 표). 상태 = `StatusMessage`(영역 0개·행 0개 → `needs_setup`, 문서 없음 → `empty` + 그 아래 버튼 줄 — `StatusMessage` 의 action 은 하나뿐이라 두 버튼은 밖에 둔다, 매핑 창·AI 다시 쓰기의 오류 → `partial_error compact`). 제목 문구는 지금 문구 그대로(A1 테스트가 본다). 기간(주) 선택은 기존 주 이동(이전·다음 주)이다 — 새 선택기를 만들지 않는다.

## Review Focus

스펙이 암시하지만 스펙의 done_when·이름 있는 테스트가 덮지 않던 입력 가운데 사람을 먼저 다치게 할 다섯이다. 각 줄의 테스트는 해당 과제에 넣었다(표지 `[RF n]`).

1. **목록 밖 팀 code** — 비활성 팀이 담당인 WBS 행, 워크스페이스 회의록에 걸린 프로젝트 전용 팀, 공유 회의록(공급자 없음). 기대: 중립 슬롯으로 그리고 깨지지 않는다. 목록 안의 같은 팀은 화면이 달라도 같은 색. 저장 색이 대문자·앞뒤 공백(`' #4F46E5 '`)이어도 팔레트 자리를 찾는다. → 과제 1 `[RF1]`·과제 2.
2. **레이아웃의 팀 읽기 실패·Next 제어 신호** — `workspaceTeams`·`projectTeams` 가 `TeamsUnavailableError` 를 던지거나 빌드·프리렌더가 `DynamicServerError` 를 던진다. 기대: 앞의 것은 로그 + 빈 목록으로 셸이 그려진다(복구 화면 유지), 뒤의 것은 삼키지 않고 다시 던진다. → 과제 4 `[RF2]`.
3. **주간 채움형의 긴 시트·390px** — main 이 `overflow: hidden` 이 되므로 시트 상자가 스스로 스크롤하지 않으면 아래 행·내보내기 버튼에 닿을 수 없다. 기대: 시트 상자 `min-h-0 flex-1 overflow-auto`, 주 이동 줄은 늘 보인다. → 과제 12 `[RF3]`(정적 단언 + 과제 15 눈확인 390).
4. **`?receipt=` 의 나쁜 값** — uuid 가 아님, 다른 프로젝트의 명령 id, 영수증 읽기 실패. 기대: 패널이 사유를 보이고 마법사는 그대로, 다른 프로젝트의 요약은 보이지 않는다(`receipt: null`). → 과제 8 `[RF4]`.
5. **개명이 다른 팀 code·이름과 대소문자·전각만 다르다**(`OPS` 가 있는데 다른 팀을 'ops'·'ＯＰＳ'로) 또는 공백뿐. 기대: 서버 거부 문구가 그 행 아래 보이고 목록은 바뀌지 않는다, 자기 code 로 되돌리는 개명은 된다. → 과제 7 `[RF5]`.

```ts
/** 팀 화면 색 슬롯(SP4 D3) — 다크 짝이 있는 테마 토큰 category-1..8. 저장 hex 를 inline 으로 그리지 않는다(다크 대비). */
export type TeamSlotStyle = { fg: string; bar: string; chip: string }
/** 슬롯을 정하는 데 필요한 팀 필드 — Team 이 그대로 맞는다 */
export type TeamColorRef = { id: string; code: string; color: string }

/** Tailwind JIT 가 읽도록 클래스는 리터럴로 둔다 */
export const CATEGORY_SLOTS: readonly TeamSlotStyle[] = [
  { fg: 'text-category-1', bar: 'bg-category-1', chip: 'bg-category-1-weak text-category-1' },
  { fg: 'text-category-2', bar: 'bg-category-2', chip: 'bg-category-2-weak text-category-2' },
  { fg: 'text-category-3', bar: 'bg-category-3', chip: 'bg-category-3-weak text-category-3' },
  { fg: 'text-category-4', bar: 'bg-category-4', chip: 'bg-category-4-weak text-category-4' },
  { fg: 'text-category-5', bar: 'bg-category-5', chip: 'bg-category-5-weak text-category-5' },
  { fg: 'text-category-6', bar: 'bg-category-6', chip: 'bg-category-6-weak text-category-6' },
  { fg: 'text-category-7', bar: 'bg-category-7', chip: 'bg-category-7-weak text-category-7' },
  { fg: 'text-category-8', bar: 'bg-category-8', chip: 'bg-category-8-weak text-category-8' },
]
/** 그 범위의 팀 목록에 없는 code(비활성 팀 담당·다른 범위의 전용 팀·공급자가 없는 공유 화면) — 슬롯을 지어내면 같은 팀이 화면마다
 *  다른 색이 된다(계획 P1). 채움 위 글자는 category-fg 그대로 대비가 선다(라이트 흰 글자/gray-600, 다크 cobalt-950/ink-d200) */
export const NEUTRAL_SLOT: TeamSlotStyle = { fg: 'text-neutral', bar: 'bg-neutral', chip: 'bg-neutral-weak text-neutral' }

function stableHash(s: string): number {
  let h = 0
  for (const ch of s) h = (h * 31 + ch.codePointAt(0)!) >>> 0
  return h
}

/** 1~8 — 저장 색이 TEAM_PALETTE 의 i 번째면 i+1(생성 순 배정 pickTeamColor 그대로라 워크스페이스 앞 다섯 팀이 서로 다르다),
 *  팔레트 밖(DB 기본값 #6b7280·직접 SQL)이면 팀 id 의 안정 해시. 전환 RPC 는 색을 그대로 복사하므로 전환한 팀의 슬롯도 그대로다 */
export function teamSlotIndex(team: { id: string; color: string }): number {
  const i = (TEAM_PALETTE as readonly string[]).indexOf(String(team.color ?? '').trim().toLowerCase())
  return i >= 0 ? i + 1 : (stableHash(team.id) % CATEGORY_SLOTS.length) + 1
}

export function teamSlot(team: { id: string; color: string }): TeamSlotStyle {
  return CATEGORY_SLOTS[teamSlotIndex(team) - 1]
}

/** code → 슬롯. teams 는 그 범위의 팀(활성) — 없으면 중립 */
export function teamSlotFor(code: string, teams: readonly TeamColorRef[]): TeamSlotStyle {
  const t = teams.find((x) => x.code === code)
  return t ? teamSlot(t) : NEUTRAL_SLOT
```

```ts
import type { Team } from '@/lib/domain/teams'

export async function activeTeamsForLayout(read: () => Promise<Team[]>, tag: string): Promise<Team[]> {
```

```ts
const ERR_NO_COMMON = '복사할 전역 팀이 없습니다.'   // 스펙 §3.3 ⑦ "지금 문구" 그대로(액션 계약)
/** 전환 RPC 의 자기 토큰(SP4 D45 — 호출부 자기 매핑). 55P03(잠금 대기 상한)·40P01 은 rpcFailure 가 재시도 문구로 */
const CONVERT_TOKENS: OwnTokenTable = {
  TEAM_CONVERT_FORBIDDEN: { status: 403, code: 'ERR_DENIED', message: ERR_DENIED },
  PROJECT_NOT_FOUND: { status: 404, code: 'ERR_MISSING', message: ERR_MISSING },
}

/** '공용 팀 전환으로 시작' — 이 프로젝트가 상속하던 공용 팀을 같은 code·이름·색·순서·활성의 전용 팀으로 바꾸고, 그 프로젝트 안의 팀 연결
 *  (작업 담당·명단 팀·업무영역 팀·수락 전 초대)을 새 팀으로 옮긴다(전환 RPC — SP4 D54·T14). 되돌리지 않는다. 옛 '복사만'은 같은 code·다른 id
 *  두 벌을 만들어 담당 팀 멤버의 실적 저장이 서버에서 거부됐다(D4). 결과 계약 { ok, error } 그대로(§3.3 ⑦) */
export async function copyGlobalTeams(projectId: string): Promise<ProjectTeamActionResult> {
  const g = await requireProjectAdmin(projectId)
  if (!g.ok) return { ok: false, error: g.error }
  const { data, error } = await createAdminClient().rpc('convert_inherited_teams', { p_actor: g.actor.userId, p_project_id: projectId })
  if (error) {
    const f = rpcFailure(error, CONVERT_TOKENS)
    if (!f) return { ok: false, error: failWith('projectTeams.convert', error, ERR_TEAM_COPY) }
    console.error('[projectTeams.convert] 전환 거부:', f.token)
    return { ok: false, error: f.message }
  }
  const r = (data ?? null) as { status?: unknown; teams?: unknown } | null
  if (r?.status === 'already') return { ok: false, error: ERR_ALREADY }
  if (r?.status !== 'converted' || typeof r.teams !== 'number') {
    return { ok: false, error: failWith('projectTeams.convert', new Error(`전환 결과의 모양이 기대와 다릅니다: ${JSON.stringify(data)}`), ERR_TEAM_COPY) }
  }
  if (r.teams === 0) return { ok: false, error: ERR_NO_COMMON }
  revalidatePath('/(app)/p/[projectId]', 'layout')
  return { ok: true }
}
```

```tsx
import { useState } from 'react'
import { Check, Pencil, X } from 'lucide-react'

const TEAM_NAME_INPUT_MAX = 40   // 서버 규칙(TEAM_NAME_MAX)과 같은 길이 — 판정은 서버가 한다

export function TeamNameCell({ team, disabled, onRename, chip }: {
  team: { id: string; code: string; name: string }
  disabled: boolean
  onRename: (name: string) => Promise<{ ok: boolean; error?: string }>
  /** 팀 색 견본(#15 — teamSlot(row).chip). 없으면 코드를 칩 없이 쓴다 */
  chip?: string
}) {
  const [editing, setEditing] = useState(false)
  const [value, setValue] = useState(team.name)
  const [error, setError] = useState<string | null>(null)
  const [saving, setSaving] = useState(false)

  async function save() {
    const name = value.trim()
    if (!name) { setError('팀 이름을 입력하세요.'); return }
    setSaving(true); setError(null)
    const r = await onRename(name)
    setSaving(false)
    if (!r.ok) { setError(r.error ?? '이름을 바꾸지 못했습니다.'); return }
    setEditing(false)
  }
  const codeLabel = chip ? <span className={`chip ${chip}`}>{team.code}</span> : <span className="text-meta text-fg-muted">{team.code}</span>

  if (!editing) {
    return (
      <div className="flex items-center gap-2">
        {chip && codeLabel}
        <span className="font-medium text-fg">{team.name}</span>
        {!chip && team.name !== team.code && codeLabel}
        <button type="button" className="btn btn-ghost btn-sm" disabled={disabled} data-team-rename={team.id}
          aria-label={`${team.name} 이름 바꾸기`} onClick={() => { setValue(team.name); setError(null); setEditing(true) }}>
          <Pencil className="h-3.5 w-3.5" />
        </button>
      </div>
    )
  }
  return (
    <div className="space-y-1">
      <div className="flex items-center gap-1.5">
        {chip && codeLabel}
        <input data-team-rename-input className="app-input w-40" value={value} maxLength={TEAM_NAME_INPUT_MAX} autoFocus disabled={saving}
          aria-label={`${team.code} 팀 새 이름`} onChange={(e) => setValue(e.target.value)}
          onKeyDown={(e) => { if (e.key === 'Enter') void save(); if (e.key === 'Escape') setEditing(false) }} />
        <button type="button" className="btn btn-primary btn-sm" data-team-rename-save disabled={saving} onClick={() => void save()} aria-label="이름 저장">
          <Check className="h-3.5 w-3.5" />
        </button>
        <button type="button" className="btn btn-ghost btn-sm" disabled={saving} onClick={() => setEditing(false)} aria-label="취소">
          <X className="h-3.5 w-3.5" />
        </button>
      </div>
      {error && <p role="alert" className="text-meta text-danger">{error}</p>}
    </div>
  )
}
```

```tsx
// 영수증은 그 실행을 한 관리자에게만, 그 프로젝트에서만 보인다(액션이 행위자·프로젝트로 거른다 — 다른 프로젝트의 id 는 receipt: null, Q14).
// 읽기 실패는 '없음'으로 위장하지 않는다 — 원문은 액션이 로그로 남겼고 화면은 사전 문구다.
import { StatusMessage } from '@/components/ui/StatusMessage'
import type { ImportReceiptResult, ImportReceiptView } from '@/app/actions/importReceipts'
import { isUuidLike } from '@/lib/domain/validate'
import { seoulStamp } from '@/lib/domain/dates'
import { t, type DictKey, type Locale } from '@/lib/i18n/dict'

export type ReceiptPanelState = { kind: 'found'; receipt: ImportReceiptView } | { kind: 'missing' } | { kind: 'invalid' } | { kind: 'error' }

/** ?receipt= → 패널 상태. 값이 없으면 패널 없음, 배열·uuid 아님은 액션을 부르지 않는다 */
export async function receiptStateOf(
  raw: string | string[] | undefined, read: (commandId: string) => Promise<ImportReceiptResult>,
): Promise<ReceiptPanelState | null> {
  if (raw === undefined) return null
  if (typeof raw !== 'string' || !isUuidLike(raw)) return { kind: 'invalid' }
  const r = await read(raw)
  if (!r.ok) return { kind: 'error' }
  return r.receipt ? { kind: 'found', receipt: r.receipt } : { kind: 'missing' }
}

export function ImportReceiptPanel({ state, locale }: { state: ReceiptPanelState; locale: Locale }) {
  const tr = (k: DictKey) => t(locale, k)
  if (state.kind === 'invalid') return <StatusMessage kind="empty" title={tr('importWizard.receiptInvalid')} />
  if (state.kind === 'missing') return <StatusMessage kind="empty" title={tr('importWizard.receiptMissing')} detail={tr('importWizard.receiptMissingDesc')} />
  if (state.kind === 'error') return <StatusMessage kind="partial_error" title={tr('importWizard.receiptError')} />
  const r = state.receipt
  const cell = (label: DictKey, value: React.ReactNode, extra = '') => (
    <div><dt className="text-meta text-fg-muted">{tr(label)}</dt><dd className={`mt-0.5 font-semibold text-fg ${extra}`}>{value}</dd></div>
  )
  return (
    <section className="card space-y-3 p-5" data-import-receipt aria-labelledby="import-receipt-title">
      <h2 id="import-receipt-title" className="text-section text-fg">{tr('importWizard.receiptTitle')}</h2>
      <dl className="grid gap-3 text-sm sm:grid-cols-4">
        {cell('importWizard.runId', <span title={r.commandId}>{r.commandId.slice(0, 8)}</span>, 'font-mono')}
        {cell('importWizard.doneMode', tr(r.mode === 'append' ? 'importWizard.modeAppend' : 'importWizard.modeReplace'))}
        {cell('importWizard.receiptCount', r.count, 'tabular-nums')}
        {cell('importWizard.receiptAt', seoulStamp(r.createdAt), 'tabular-nums')}
      </dl>
    </section>
  )
}
```

```js
/**
 * SP4 B — 화면 HTML 의 팀 색 클래스(teams-color-render, 스펙 §6.3). slots = category-1..8 의 text·bg(중복 없이 — 채움 위 글자 category-fg 와
 * -weak 배경은 세지 않는다), legacy = 옛 team-1..5 클래스(-weak 포함 — 0 이어야 한다), neutral = 목록 밖 팀의 중립 슬롯 수(기록만).
 * @param {string} html @returns {{ slots: string[], legacy: string[], neutral: number }}
 */
export function teamSlotVerdict(html) {
  const text = String(html)
  const uniq = (re) => [...new Set([...text.matchAll(re)].map((m) => m[0]))].sort()
  return {
    slots: uniq(/(?<![\w-])(?:text|bg)-category-[1-8](?![\w-])/g),
    legacy: uniq(/(?<![\w-])(?:text|bg)-team-[1-5](?:-weak)?(?![\w-])/g),
    neutral: (text.match(/(?<![\w-])(?:text|bg)-neutral(?![\w-])/g) ?? []).length,
  }
}
```

```js
const PALETTE = ['#4f46e5', '#0276a8', '#7c3aed', '#a65b00', '#0f766e']

    before: `team-${(hash(t.code) % 5) + 1}`, after: `category-${i >= 0 ? i + 1 : (hash(t.id) % 8) + 1}` }

async function inPage([width, height], theme, fn) {
  const context = await browser.newContext({ viewport: { width, height }, colorScheme: theme, locale: 'ko-KR' })
  const page = await context.newPage()
  const errs = []
  page.on('pageerror', (e) => errs.push(String(e)))
  try {
    await page.goto(`${BASE}/login`)
    await page.fill('#email', 'admin@example.com')
    await page.fill('#password', password)

    await fn(page, errs)

    results.push({ theme, size: `${width}×${height}`, error: String(e?.message ?? e).slice(0, 300) })
  } finally { await context.close() }
}
async function shot(page, errs, row, [w, h], theme, extra = {}) {
  const file = join(outDir, `${row}-${theme}-${w}x${h}.png`)

  const v = teamSlotVerdict(await page.content())

    sha: createHash('sha256').update(readFileSync(file)).digest('hex').slice(0, 12),
    dark: await page.evaluate(() => document.documentElement.classList.contains('dark')), errors: [...errs], slots: v.slots, legacy: v.legacy, ...extra })

      await page.locator('[data-wbs-weekly-report]').first().click()

      await open(page, `/p/${A2}/settings#project-team`)
      const convert = page.getByRole('button', { name: '공용 팀 전환으로 시작' })
      const inherited = await convert.count()
      if (inherited) { await convert.click(); await page.locator('[role="dialog"]').first().waitFor() }
      await shot(page, errs, 'settings-teams-convert', size, theme,
        { inherited, dialog: inherited ? await page.locator('[role="dialog"]').first().innerText() : null })
      await open(page, `/p/${I}/import?receipt=${K}`)
      await shot(page, errs, 'import-receipt', size, theme, { receiptPanel: await page.locator('[data-import-receipt]').count() })
    })
  }
  const weeklySizes = { light: [[1440, 900], [1280, 720], [768, 1024], [390, 844]], dark: [[1440, 900], [390, 844]] }
  for (const [theme, sizes] of Object.entries(weeklySizes)) for (const size of sizes) {
    await inPage(size, theme, async (page, errs) => {
      await open(page, `/p/${B}/weekly`)
      const box = page.locator('div.isolate.min-h-0.flex-1.overflow-auto').first()
      const geo = await box.evaluate((el) => ({ scrollH: el.scrollHeight, clientH: el.clientHeight }))

        { bottomReached: await box.evaluate((el) => Math.abs(el.scrollHeight - el.clientHeight - el.scrollTop) < 2) })
    })
  }
} finally {
  await browser.close()
  writeFileSync(join(outDir, 'eye-b.json'), JSON.stringify(results, null, 2))
}
```
