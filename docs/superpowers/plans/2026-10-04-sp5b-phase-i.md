## 결정 기록(구현 중)

- 액션은 정의를 다시 읽지 않는다 — 판정 한 곳(DB 트리거), 화면 선택지는 `allowedTargets` 로 같은 규칙. 스펙 D6 의 "정의 로드" 는 비평 F-1 대안대로
  빼고 오류 토큰 매핑만 둔다(기존 액션 테스트 mock 변경 최소화).
- 같은 code 로의 UPDATE 는 DB 에서 변경 없음(통과·이력 0) — TS 는 선택지에서 뺀다. 골든은 이 차이를 테스트에 적었다.
- 등록의 격리 수준 거절은 채번 트리거가 먼저 낸다(`ISSUE_CODE_ISOLATION`) — 상태 트리거의 25001 은 전이(UPDATE)에서 본다.
- 프로젝트 정의를 싣지 않는 화면(회의록 칩·포털)은 범주로 그린다.
- `ISSUE_STATUS_META` 는 대시보드 범주 카드(결정 3 — 집계 고정)가 계속 쓴다 — `no-runtime-constants` 영구 가드로 올리지 않는다(스펙 §6.1 의 그 줄은 Z 에서 정정).
- 관찰(SP5b 밖, main 에서도 재현): 이슈 딥링크(`?focus=`) 모달 첫 렌더에 간헐 React #418(수화 불일치).
