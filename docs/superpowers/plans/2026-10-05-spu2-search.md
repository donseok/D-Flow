## 1. 배경 및 목표

1. **⌘K / 전역 검색 (UX-04, 찾기 v1 §5.3.7)**:
   - 전역 바(`GlobalBar.tsx`) 중앙 검색창 클릭 또는 `Cmd+K`/`Ctrl+K` 단축키로 검색 다이얼로그 오픈.
   - 범위 칩: `[워크스페이스 전체]` vs `[현재 프로젝트]` 토글.
   - 결과 분류:
     - **이동 (Navigation)**: `navFor` 항목(프로젝트 화면, 워크스페이스 화면, 설정 범주).
     - **찾기 (Search)**: 프로젝트 목록(이름 일치), WBS 작업 항목(코드 및 제목 일치).
   - 서버 측 RLS / 세션 클라이언트 검증: 권한 있는 항목만 노출, 미색인/실패/0건 명시적 구분.
2. **WBS 그리드 키보드 포커스 모델 (D6-§8-grid, `itemId+fieldId`)**:
   - `itemId + fieldId` 기반의 안정적 포커스 추적.
   - 방향키(↑↓←→)로 셀 간 이동, Shift+방향키 범위 선택, Enter/F2로 편집 시작, Tab/Shift+Tab으로 다음/이전 셀 이동.
   - 가상화, 정렬, 원격 갱신 후에도 `itemId+fieldId` 포커스 복원 유지.
   - 행 체크 선택과 셀 범위 선택의 상태 분리.
3. **승인 검토 화면 (제6부 §8, D6-§2-approval, Q09)**:
   - `ApprovalQueue.tsx` / 검토 화면:
   - 제출 revision 및 command ID 보존.
   - 유효 시간대(`viewTimezone`) 및 locale 준수 (클라이언트 시간 불변식 준수).
   - 검토 중 타인 처리, 재제출, 권한 회수 시 Stale/오래된 revision 승인 차단 (CAS 원칙).
4. **'내 업무' (`/w/[slug]/my-work`) 화면 완성 (D5-§3, §5.9.1)**:
   - `getMyWork` 기반 검증된 읽기 모델 연결.
   - 탭: `[내 작업]`, `[검토 대기]`, `[알림]`.
   - 알림 탭은 기존 알림함(`InboxPanel`) 통합.
   - 기한 지연일수 / 오늘 마감 칩 및 유효 타임존 기반 날짜 표시.
5. **WBS 보드 '흐름' 그룹 보기 및 카드 이동 메뉴, 이슈 보드 열 파생 (D8, D17, §5.12.5 ②)**:
   - WBS 보드: '상태' 그룹 외에 '흐름(단계: `as/ip/im/xx`)' 그룹 보기 추가.
   - `im` 열 부제에 승인 단계(`workflow.approval_steps`) 표시.
   - 카드 이동 메뉴: 드래그 앤 드롭뿐만 아니라 키보드/메뉴를 통한 단계 이동 지원.
