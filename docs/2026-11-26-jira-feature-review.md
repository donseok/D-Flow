# D-Flow 에 들일 만한 Jira 기능 검토 (2026-11-26)

화이트보드: https://claude.ai/artifact/HwMGwLq5k1WvWJC5WP1M2n (비공개 — 공유 메뉴에서 열어야 다른 사람이 본다)

방법: 영역 6개(계획·작업 항목·협업·검색/보고·자동화/연동/AI·화면 UX)에서 Jira 기능 112개를 코드·매뉴얼과 대조했다.
영역마다 검증자가 상태·비목표·가치/비용 판정을 반박 검증했고, 2024~2026 Jira 신기능은 공식 릴리스 노트로 확인했다.
결론: Jira 를 복제하지 말고 WBS 중심 모델의 빈칸을 메운다. 비목표(정본 §1.5 "재제안 금지")에 걸리는 것은 넣지 않는다.

## 이미 있음 (Jira 대응)

| Jira | D-Flow |
|---|---|
| 에픽·계층 | N단 WBS + 가중 롤업 |
| 타임라인·의존 | 간트, 선행 FS/SS·대기 영업일, 크리티컬 패스, 영향 검토 창 |
| 번업·지표 | S-커브, SPI, 미해결 추이(생성 대비 해결) |
| 승인·내 업무·보드 | 1~3단계 승인(자기 승인 차단), 내 업무, 칸반 |
| Agents in Jira(2026-05 GA) | 에이전트 오피스·작업 API |

## 1순위 — 효과가 크고 바로 쓰인다

| 기능 | 지금 | 비용 |
|---|---|---|
| 이슈↔WBS 작업 연결 + 작업에서 "막힘 이슈" 바로 등록 | 회의록 문단을 거친 간접 연결뿐(`issue_links`·`wbs_item_links` 가 `minute_block` 만 허용) | M (등록 단추 S) |
| WBS 작업 댓글(@멘션) | 작업 단위 논의·반려 사유 자리가 없음 | M |
| 이슈 검색·필터 + 주소에 필터 보존, ⌘K 이슈 찾기 | 이슈 화면에 글자 검색 없음(매뉴얼 05) | S~M |
| 이슈 목록 Excel 내보내기(이슈관리대장) | 이슈를 파일로 받을 길이 없음 | S |
| 알림함 개선 — 항목으로 바로 이동, 발행되지 않는 토글 7종 정리 | 배정·승인 알림이 목록 화면으로 감 | S~M |
| AI 주간보고 초안 — WBS 실적을 주간 시트 칸 초안으로 | 결정형 추출·"AI로 다시 작성" 창은 있고 시트 칸으로 넣는 길만 없음 | M |
| 일정 기준선(baseline) | 재계획 흔적이 남지 않음(감리·변경관리 대응) | L |

## 2순위 — 할 만하지만 급하지 않다

- WBS 정리: 상위 이동(들여·내어쓰기 — 지금은 구조를 고치면 이력·첨부를 잃는다), 실제 착수·완료일 기록, 의존 날짜 충돌 모아보기
- 사람·계획: 사람별 작업량 + 근태 히트맵(Jira 2026-07 Capacity 와 같은 방향), 주간 계획 고정 후 약속 대비 실적
- 승인·이슈: 승인 대기 큐(사람 작업의 검수 대기 포함), 이슈 경과일·평균 해결 시간, AI 도우미 이슈 읽기 도구
- 공유·연동: 링크 복사 단추, 회의 안내 메일 `.ics` 첨부, 에이전트 `human_gate` 알림 발행

## 넣지 않는 편이 좋다

- 비목표: 자동화 규칙(N12), 스마트 커밋(N12), 앱 마켓플레이스(N10), 필터 메일 구독·이메일 요약(N18)
- 방식이 맞지 않음: JQL(자연어 조회는 AI 도우미), 작업별 시간 기록, 투표, SLA, 외부 요청 포털, 보드 WIP 제한, 목표/OKR
- 보류: 스프린트 — 실행 리듬이 주간이라 "주간 계획 고정"이 효과 대부분을 더 싸게 준다

## 확인 필요 — 작업 트리의 미커밋 Jira 확장(`0062_jira_extensions`)

검토 중 다른 세션이 같은 작업 트리에 만든 미커밋 작업에서 검증자가 찾은 점이다(이 문서 커밋에는 들어 있지 않다).

- `project_automation_rules` 의 `condition_json`·트리거 종류 → 비목표 N12 와 겹친다.
- `issue_field_logs`(이슈 필드 변경 이력) → N14 의 "이슈 필드 값 이력" 비목표에 걸릴 수 있다.
- `project_board_policies`(WIP 제한)가 설정 레지스트리 밖 새 표라 설정 이력·`copy_project_config` 복사에서 빠진다.
