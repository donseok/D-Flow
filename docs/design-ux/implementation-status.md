# 디자인 개선 실행 기록

기준일: 2026-10-11. 공통 UI와 이슈 접근성에 이어 실제 계정 검증 및 주요 업무 화면 개선을 진행했다. 전체 수행계획의 최종 사용자 검토는 아직 완료되지 않았다.

## 적용한 변경

- 로그인: 비밀번호 표시 버튼 44×44px, 표시 상태와 오류 연결을 보조기기에 전달.
- 페이지 제목: 긴 제목 줄바꿈, 좁은 화면에서도 부가 정보 유지, 액션 줄바꿈.
- 사이드바: 자동으로 접히는 폭에서도 아이콘 설명 툴팁 제공.
- 폼·탭: 라벨과 작은 탭 글자 14px, 탭 방향키·Home·End 및 단일 Tab 진입점.
- 모달: 배경 흐림 제거, 제목 스타일 통일. 우측 패널 닫기 버튼 44×44px.
- 에이전트: 수치는 본문 전경색으로 표시하고 상태 색은 보조 표시로 유지. 좌석 지도 글자에 공통 색상 토큰 사용.
- 이슈: 필터 초기화, 보기·상태·심각도 탭 이름, 제목을 기본 버튼으로 조작. 행 자체를 버튼으로 읽는 구조 제거.

기존 밝은 화면과 코발트 포인트를 유지하며 장식보다 글자 위계와 간격, 조작성을 정돈했다. 새로운 이미지·그라데이션·장식 카드 시스템은 추가하지 않았다.

## 추가 적용한 변경

- 이슈: 768px 미만에서는 제목·상태·담당자·기한 중심의 세로 목록. 추가 정보는 펼침으로 확인하며 표와 선택·필터·페이지 상태를 공유한다.
- WBS: 모바일 도구 그룹이 검색 아래에서 화면 폭을 사용하도록 변경. 글자 크기 조절 버튼 확대. 저장된 확대 배율은 유지.
- 주간보고: 업무 본문 14px와 셀 여백, 좁은 화면의 가로 이동 안내, 키보드로 진입 가능한 표. 모바일 도구 줄과 PPT 버튼 이름을 간결하게 정돈.
- 회의록: 긴 제목 줄바꿈과 제목 위계 통일, 집중 모드·글자 크기 조절 버튼 확대. 기존 본문 글자 크기 설정은 유지.
- 홈·설정·대시보드 공통: 모바일 요약 지표의 균일한 배치, SectionCard의 긴 제목과 액션 줄바꿈.
- 포트폴리오: 표 본문 14px, 긴 프로젝트 이름 줄바꿈, 키보드 스크롤 진입점, 실제 12px의 월 눈금. 9999년 말에서 월 눈금 생성이 종료되지 않는 문제를 숫자 기반의 제한된 눈금으로 수정.
- 긴 일정 계산: 메인 DB의 0001~9999년 일정에서 근무일을 날짜마다 순회하는 병목을 전체 주 수와 예외 날짜 계산으로 교체. 업무 날짜 데이터는 수정하지 않았다.
- WBS(전체 캡처에서 발견): 좁은 화면에서 접힌 도구 모음의 플로팅 열기 버튼이 '프로젝트 기간 밖' 안내 문구 끝을 덮던 것을, 버튼이 떠 있는 동안 안내 오른쪽을 비워 해결. 아이콘뿐인 도구 모음 토글에 보조기기용 이름 추가.
- 에이전트 위임 표(전체 캡처에서 발견): 접기(14px)·프롬프트 편집(12px) 버튼의 누르는 영역을 24px로 확대. 행 높이는 그대로다.

## 계정과 환경

사용자가 계정을 직접 확인해 진행하도록 요청한 뒤, 실행 중인 메인 개발 DB의 기존 플랫폼 관리자 계정으로 인증했다. 비밀번호를 재설정하거나 새 계정을 생성하지 않았으며 로그인 이메일도 발송하지 않았다. 환경 파일과 세션 값은 저장소·대화에 공개하지 않았다.

작업 폴더의 54521 전용 DB는 실행 중이 아니었다. 메인 54321 개발 DB를 사용하는 별도 소스 사본에서 검증했으며 기존 3000 서버와 작업 폴더의 환경 파일은 변경하지 않았다. 회의록은 실제 데이터가 없어 별도 미리보기 사본에만 검증용 문서를 만들었다. 제품 소스에는 검증용 페이지가 포함되지 않는다.

```sh
python3 scripts/design-rollback.py
python3 scripts/design-rollback.py --apply
python3 scripts/design-rollback.py --group issues --apply
python3 scripts/design-rollback.py --group weekly --apply
python3 scripts/design-rollback.py --reapply --apply
```

기본 명령은 검사만 수행한다. `--apply` 실행은 기록된 파일의 SHA-256을 전부 먼저 확인하고 원복 직전 파일을 별도 임시 폴더에 저장한다. 후속 수정이 있으면 파일을 변경하지 않고 중단한다. 원복 기록은 `rollback-manifest.json`에 있으며 데이터·환경변수·기존 `supabase/config.toml` 수정은 대상에 포함되지 않는다. 원복 또는 재적용 후 실행 중인 앱은 재빌드/재시작해야 한다.

## 남은 작업

전체 화면 캡처와 최종 검사는 끝났다. 아래는 캡처·측정에서 확인했지만 이번에 고치지 않은 항목이다.

- 작업 계획 간트의 날짜·주 눈금 글자가 9~9.5px다(확대 배율 100% 기준, 화면당 약 110곳). 밀도를 위한 기존 설계라 그대로 두었다 — 키우면 하루 칸 폭과 확대 단계 전체가 바뀌므로 별도 결정이 필요하다.
- 설정 화면의 체크박스·라디오는 브라우저 기본 13px이다(프로젝트 설정 62개, 워크스페이스 설정 46개). 라벨을 눌러도 되는지 화면별로 확인하고 공통 체크박스 크기를 정할지 결정해야 한다.
- 에이전트 위임 표의 열 너비 손잡이(9px)는 데스크톱 포인터용이라 그대로 두었다.
- 모달·우측 패널·빈 상태 이외의 상태(오류·로딩·권한 없음)와 데이터가 많은 화면(작업 수백 행, 긴 회의록)은 아직 눈으로 보지 않았다. 메인 DB에 그런 데이터가 없다.
- 최종 사용자 디자인 검토는 아직 받지 않았다. 브랜치는 push 하지 않았다.

이후 변경마다 원복 manifest 범위를 갱신하고 시각 검증·필요한 회귀 검증을 수행한다. 기존 글자 크기와 패널 선호값은 보존한다.
