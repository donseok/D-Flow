# 디자인 변경 반영 확인

확인일: 2026-10-11. 현재 소스·실행 버전: `ca07e892`.
대조 기준: `docs/2026-10-11-design-ux-improvement-plan.md`, 실제 적용 기록과 이후 사용자 결정.

## 판정

실제로 적용했다고 기록한 주요 디자인 변경은 현재 소스와 실행 화면에서 확인된다. 그러나 원래 계획서의 모든 개선 제안과 검증 조건을 완료한 것은 아니다. 계획서 자체도 모바일 카드·편안한 밀도 등은 검토안이며 모두 구현하기로 확정한 사항이 아니라고 명시한다.

## 반영 확인

| 영역 | 현재 결과 | 확인 근거 |
|---|---|---|
| 로그인 | 비밀번호 표시 버튼 44×44px, 데스크톱·모바일 넘침 없음 | 실행 측정, 오류/표시 상태 연결은 소스 확인 |
| 페이지 제목·공통 폼 | 제목 줄바꿈, 모바일 메타 유지, 액션 줄바꿈, 공용 Field 라벨 14px | 소스 및 설정·이슈 등 화면 |
| 사이드바 | 접기 버튼 상단 배치, 자동 접힘에도 툴팁을 제공하는 조건 | 화면 및 NavList 소스 |
| 탭 | 작은 탭도 14px, 방향키·Home·End와 단일 Tab 진입점 | 실행 글자 측정, 관련 테스트 |
| 모달·우측 패널 | 모달 배경 흐림 제거, 제목 통일, 패널 닫기 44×44px | 소스·관련 회귀 테스트; 이번 실행에서 모든 모달을 열지는 않음 |
| 이슈 | 모바일 세로 목록, 제목 버튼, 필터 초기화 | 390px 실제 목록, 필터 선택→초기화 동작, 회귀 테스트 |
| 작업 계획 | 도구 모음 상시 표시, 모바일 줄바꿈, 작업명 검색 제거, 확대 조절 버튼 | 1440·390px 캡처, 소스·회귀 테스트 |
| 주간보고 | 본문 14px·여백, 모바일 가로 이동 안내, 간결한 PPT 버튼 | 실제 데이터 화면, 소스·회귀 테스트 |
| 회의록 | 제목 줄바꿈·집중 모드·글자 조절 버튼 개선 | 소스·회귀 테스트; 현재 상세 문서는 실행 검증하지 않음 |
| 포트폴리오 | 표 본문 14px, 긴 이름 줄바꿈, 키보드 스크롤 진입점 | 소스 및 실제 화면 |
| 에이전트 | 수치를 본문 전경색으로 표시, 제목 위계 통일, 작은 표 버튼 영역 확대 | 실제 화면 및 소스 |
| 회의·근태 | 월 달력 높이 맞춤 | 실행 캡처 및 month-fit 테스트 |

작업 계획의 도구 모음 토글 및 작업명 검색은 후속 사용자 요청으로 제거됐으므로 초기 적용 기록과 달라도 누락으로 판정하지 않았다. 간트 9~9.5px 눈금과 기본 체크박스·라디오 크기는 유지하기로 한 사용자 결정을 존중한다.

## 이번 검증 범위

- 기존 로컬 main의 프로덕션 빌드를 3000에서 기동하고, 중지돼 있던 Colima의 기존 DB 환경을 기동했다. DB 초기화·테스트 업무 데이터 생성은 하지 않았다.
- 프로젝트 12화면, 워크스페이스 6화면, 내 계정 1화면을 1440×900·390×844에서 확인했다. 실제 viewport 너비를 측정해 38개 모두 요청한 너비와 일치함을 확인했다.
- 38개 모두 로그인으로 튕기지 않았고, h1이 존재하며, 페이지 전체 가로 넘침과 내용 있는 오류 알림이 없었다. 이는 기본 상태 점검이며 모든 저장·권한·오류 상태의 통과를 의미하지 않는다.
- 작업 계획·이슈·주간보고·에이전트·근태·설정의 주요 캡처를 육안 검토했다. 모든 화면 캡처를 픽셀 단위로 정밀 검토한 것은 아니다.
- 이슈 필터를 진행중으로 바꾸면 초기화 버튼이 나타나고, 초기화하면 전체로 돌아가는 동작을 확인했다.
- 관련 12개 테스트 파일, 187개 테스트가 통과했다. 페이지 머리·터치 크기·대비 토큰·최소 글자·반응형 안전망·탭 키보드·WBS 모바일·회의록 글자 조절·이슈 일괄 선택·주간 시트·월 높이 계산을 포함한다.
- 캡처와 측정 JSON: `/tmp/dflow-design-review-20261011/`. 임시 폴더이므로 영구 보관 자료는 아니다. 세션 토큰·환경 변수는 저장하지 않았다.

## 미구현 또는 미검증 범위

- 주간보고·멤버의 모바일 전용 카드, WBS 편안한 밀도, 선택 열 중심 보드 등의 비교안은 이번 디자인 구현 범위에 포함되지 않았다. 현재 주간보고와 넓은 표는 영역 내부 가로 스크롤을 유지한다.
- 회의록 기본 16px 비교안과 목차·채팅 재배치는 적용하지 않았다. 기존 사용자 글자 크기·집중 모드 선택을 유지한다.
- 위키 장문·관리자·사용 현황·가져오기 등 각 화면의 개별 개편은 공통 UI 반영과 구별해야 한다. 현재 기본 화면 확인으로 전체 계획의 개별 개선 완료를 주장할 수 없다.
- 많은 행·긴 문서·다중 역할·권한 없음·저장 충돌·폰트 실패·실기기·실제 200/400% 확대·PPTX/XLSX 출력은 이번에 검증하지 않았다.
- 디자인 만족도는 사용자 평가가 필요하며 테스트 결과로 대체하지 않는다.

## 기록 보완 필요

- 과거 실행 기록의 “브랜치는 push 하지 않았다”는 문구는 최신 상태와 다르다. `ca07e892`는 main에 반영됐고 CI도 성공했다.
- 원복 manifest는 후속 사용자 변경 이전 버전이다. 검사 전용 `python3 scripts/design-rollback.py`는 `NavList.tsx`의 후속 수정을 감지해 중단했다. 어떤 파일도 원복하지 않았다. 현재 버전 전체를 원복하려면 후속 기능 변경을 보존하도록 기록과 원복 범위를 다시 정해야 한다.

이번 작업에서는 제품 코드를 수정하거나 커밋·push하지 않았다.
