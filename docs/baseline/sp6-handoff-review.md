## 이번 재검증에서 확인한 결함

- form_templates가 기본 DB 권한을 상속해 authenticated에 정책 없는 INSERT/UPDATE/DELETE 권한이 남았다.
- SP6 참조 검사 교체가 SP5c의 값이 있는 필드 타입 변경 및 범위 축소 검사를 누락했다. 기존 두 연결 경합 검사도 실패했다.
- form-templates 버킷 정책이 일반 첨부 경로 파서를 호출해 정상 incoming 업로드를 거부했다.
- form_template_key_in_use는 실제 행위자 스코프 없이 authenticated가 실행할 수 있었고 엔티티 구분 없이 다른 필드까지 참조 중으로 판정했다.
- 새 테이블의 전수 격리 판별 맵·실제 격리 픽스처·UPDATE 권한 계약 등록이 없었다. 양식 RLS 테스트는 롤백된 픽스처를 다른 연결에서 조회했고, 스위트 초기화는 이미 적용된 마이그레이션을 영구 재적용했다.

기준선 DB 검사: 47파일 878건 중 12건 실패. 0033_form_template_guards로 기존 데이터·API를 유지하며 DB 가드와 전용 경로 정책을 복구한다. 새 양식 경로 파서는 기존 첨부 경로 판정을 넓히지 않는다. 기존 마이그레이션을 덮어쓰지 않고 별도 롤백을 둔다.
