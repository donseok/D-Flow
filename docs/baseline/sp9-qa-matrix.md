## 3. J1~J3 사용자 여정 워크스루 기록

### J1: 신규 관리자 온보딩 여정 (Initial Admin Onboarding)
1. **여정 단계**:
   - 워크스페이스 관리자로 로그인 후 신규 프로젝트 생성 (`/w/[slug]/projects`).
   - 프로젝트 설정 화면 진입 시 **준비 체크리스트** 자동 안내 확인:
     - 1단계: 프로젝트 기본 정보 (코드, 식별자, 설명).
     - 2단계: 사용할 모듈 선택 (WBS, 이슈, 주간보고, 회의록, 에이전트 등).
     - 3단계: 프로젝트 달력 및 업무 규칙 (주 시작 요일: 일요일/월요일, 근무일, 타임존).
     - 4단계: 첫 데이터 등록 (WBS 엑셀 양식 업로드 또는 직접 입력).
2. **검증 결과**:
   - 체크리스트 각 단계 간 이어하기/건너뛰기 정상 작동.
   - 브라우저 새로고침 후에도 계정/프로젝트별 진행 상태 유지 확인.
   - **판정: 통과 (Pass)**

### J2: 반복 작업자 일상 여정 (Daily Contributor Workflow)
1. **여정 단계**:
   - 로그인 후 `/w/[slug]/my-work`에서 '내 작업' 및 '검토 대기' 확인.
   - 담당 프로젝트 WBS 화면(`/p/[id]/wbs`) 이동 후 다중 행 선택.
   - 하단 대량 작업 바를 통해 진척률 및 상태 일괄 수정 실행.
   - 의존 관계가 있는 간트 뷰(`/wbs?view=gantt`)에서 바 드래그로 일정 연기 및 영향 검토.
   - 작업 완료 후 승인 단계 제출 (`im` 상태 전이).
2. **검증 결과**:
   - WBS 대량 수정 모달에서 선택 행 정확히 반영, CAS 충돌 없이 원자적 갱신 성공.
   - 간트 드래그 시 근무일(`working_days`) 및 휴일(`holidays`)이 정확히 계산되어 후속 태스크 이동.
   - **판정: 통과 (Pass)**

### J3: 조직 관리자 고급 운영 여정 (Advanced Workspace Ops)
1. **여정 단계**:
   - 워크스페이스 관리자로 진입하여 `/w/[slug]/admin/teams`에서 조직 개편에 따른 팀 신설.
   - 신설된 팀에 맞춰 회의록 루트 폴더(`team_root`) 자동 연동 확인.
   - 프로젝트 설정(`/p/[id]/settings`)에서 승인 단계(1~3단계) 및 어휘 분류 커스텀 변경.
   - 다른 관리자의 동시 설정 저장 시나리오에서 409 충돌 발생 및 최신 리비전 안전 병합 확인.
2. **검증 결과**:
   - `0039` 마이그레이션 적용 후 `teams` 직접 쓰기 경로 차단 및 `create_team` RPC 정규 경로 작동.
   - 설정 리비전 낙관적 잠금으로 인한 데이터 손실 0건.
   - **판정: 통과 (Pass)**

## 4. 토큰 및 별칭 상태 결론

- **다크 기본값**: `src/lib/theme/policy.ts`의 `THEME_UNSET_DEFAULT = 'system'`으로 전환 완료.
- **삭제 토큰 (`DELETED_TOKENS`)**: `hero-from/via/to`, `sheet-gutter`, `sidebar-*`, `team-1..5` 등 22개 레거시 토큰은 소스코드 전체에서 0건으로 완전 제거 확인 (`tests/css/token-aliases.test.ts` 42개 통과).
- **호환 별칭 (`ALIASES`)**: `@theme inline` 내 25개 별칭은 기존 컴포넌트 하위 호환성을 위해 안전하게 보존 중이며, 색상 왜곡 없이 의미 토큰과 1:1 매핑 유지.
