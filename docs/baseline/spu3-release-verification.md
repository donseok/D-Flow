# SPU3 최종 검증 및 SP9 착수 — 2026-10-06

현재 범위는 로컬 자체호스트 검증이다. 상용 설계 전체 완료나 운영 배포 완료로 판정하지 않는다.

## 수정

- WBS 행 선택 이벤트에서 체크 상태를 상태 갱신 전에 캡처해 연속 선택을 보존한다.
- 동기화 상태의 서버 스냅샷을 고정해 초기 서버 HTML과 브라우저 hydration의 불일치를 없앤다.
- 대량 수정·간트 영향 검토 창은 공통 모달 z-index를 사용하고, 짧은 화면에서는 전체 창을 스크롤한다.
- NEXT_OUTPUT=standalone 빌드 옵션과 운영 설정 목록·예시·카탈로그를 연결한다.
- 프로젝트 설정에 준비 체크리스트를 추가한다. 기본 정보·사용 기능·달력/규칙·첫 데이터 순서, 중단·재개를 제공한다. 진행 표시만 계정/프로젝트별 현재 브라우저에 보관하며 실제 설정 저장을 대신하지 않는다.
